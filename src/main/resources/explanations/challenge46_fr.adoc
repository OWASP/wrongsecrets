=== Injection de modèle HashiCorp Vault

Les secrets peuvent être récupérés depuis Vault à l'aide du conteneur sidecar Vault Agent (https://developer.hashicorp.com/vault/docs/platform/k8s/injector), qui s'exécute en parallèle de votre conteneur d'application principal. Ce sidecar peut injecter les secrets dans l'environnement de votre application.
 Une solution consiste à enregistrer les secrets dans un fichier. Ce fichier peut ensuite être utilisé par votre application cible. Cependant, dans ce cas précis, le développeur n'était pas certain que le fichier soit correctement pris en compte ; aussi, au lieu d'exporter le secret comme variable d'environnement, il l'a affiché avec la commande `echo`.
