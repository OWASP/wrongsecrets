=== Ескалація привілеїв сервера MCP через обліковий запис служби Google

Протокол контексту моделі (MCP) дозволяє помічникам та агентам штучного інтелекту використовувати інструменти та отримувати доступ до зовнішніх служб. Коли сервер MCP налаштовано з обліковим записом служби Google, який має ширші дозволи, ніж користувач, що викликає, це створює вразливість ескалації привілеїв: будь-хто, хто може викликати інструмент MCP, отримує доступ до ресурсів, до яких він не має безпосереднього дозволу доступу.

Цей челендж демонструє реалістичний сценарій, коли розробник створив MCP-сервер, щоб допомогти помічнику зі штучним інтелектом отримувати доступ до внутрішніх документів Google Диска. Обліковий запис служби, який використовується MCP-сервером, має доступ на читання до документа з обмеженим доступом, але MCP-сервер не перевіряє, чи абонент має право доступу до нього.

**Ваша мета:**

1. **У цій програмі працює MCP-сервер**, доступний через кінцеву точку `/mcp62`
2. **Сервер надає доступ до інструменту `read_google_drive_document`,** який використовує обліковий запис служби Google.
3. **Обліковий запис служби має доступ для читання документа Google Диска**, що містить секретний код
4. **Інструмент не перевіряє, чи має абонент право доступу** до цього документа.

**Як взаємодіяти із сервером MCP:**

Спочатку ознайомтеся з доступними інструментами:

[source,bash]
----
curl -s -X POST http://localhost:8080/mcp62 \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
----

Потім викличте інструмент `read_google_drive_document`, щоб отримати вміст документа:

[source,bash]
----
curl -s -X POST http://localhost:8080/mcp62 \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"read_google_drive_document","arguments":{}}}'
----

****
💡 *Примітка:*

Сервер зчитує документ Google Диска за допомогою налаштованого облікового запису служби. Вміст документа містить секретний ключ, який вам потрібно надіслати як відповідь. Ключова інформація щодо безпеки полягає в тому, що обліковий запис служби сервера MCP має привілейований доступ, якого зазвичай не маєте ні ви, ні ваш помічник зі штучним інтелектом, але сервер MCP неявно надає його всім, хто викликає його інструменти.
****

**Деталі реалізації (для розробників):**

- Відповідь на завдання витягується з вмісту між `<secret>` та `</secret>`.
- Вилучення виконується один раз під час завантаження секрету, а потім кешується для перевірки відповіді.
- Контролер MCP кешує отримані документи, завжди зберігаючи налаштований документ за замовчуванням плюс до 20 додаткових ідентифікаторів документів.
