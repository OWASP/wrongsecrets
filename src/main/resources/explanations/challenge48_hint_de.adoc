Diese Herausforderung kann auf folgende Weise gelöst werden:

- Entschlüssele das versiegelte Geheimnis mithilfe des im Repository befindlichen zugänglichen privaten Schlüssels:
  1. Klone das Repository, das die Challenge-Dateien enthält.
  2. Suche die Datei `sealed-challenge48.json` im Repository.
  3. Suche im Repository nach der unverschlüsselten privaten Schlüsseldatei mit dem Namen `main.key`.
  4. Verwende das Tool `kubeseal`, um das versiegelte Geheimnis zu entschlüsseln:
     ``
     kubeseal --recovery-unseal --recovery-private-key k8s/main.key < k8s/sealed-challenge48.json > unsealed-secret.yaml
     ``
  5. Die Datei `unsealed-secret.yaml` enthält das unversiegelte Geheimnis, das Base64-kodiert ist. Wir müssen es dekodieren, und der resultierende Text ist die Antwort.

- Erhalte direkten Zugriff auf das Geheimnis:
  1. Führe mit Zugriff auf den Cluster den Befehl `kubectl get secret challenge48secret -o yaml` aus.
  2. Entschlüssele das Geheimnis.


Hinweis: Stelle sicher, dass du über eine gültige Kubernetes-Konfiguration und Zugriff auf einen Kubernetes-Cluster verfügst. Falls du dies in einer gehosteten Umgebung ausführst, in der du keinen direkten Zugriff auf den Kubernetes-Cluster hast, bitte den Anbieter der gehosteten Lösung, die Befehle für dich auszuführen und dir die Ergebnisse mitzuteilen.
