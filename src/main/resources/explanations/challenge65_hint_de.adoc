Diese Aufgabe verwendet eine einfache Java CLI JAR-Datei.

Sie können es lösen, indem Sie:

1. Finden Sie die kompilierte Klasse, die das Geheimnis enthält:
- Laden Sie `wrongsecrets-java.jar` herunter.
- Führen Sie `jar tf wrongsecrets-java.jar` aus und suchen Sie nach `io/github/owasp/wrongsecrets/WrongSecretsPlain.class`.
- Öffnen Sie diese Klasse in CFR, JADX, IntelliJ IDEA oder einem anderen Dekompiler.

2. Überprüfen Sie, wie das Geheimnis gespeichert wird:
- Führen Sie `javap -c -p -classpath wrongsecrets-java.jar io.github.owasp.wrongsecrets.WrongSecretsPlain` aus.
- Suchen Sie die Methode `getSecret()` und sehen Sie sich die von ihr verwendete `ldc`-Anweisung an.
- Beachten Sie, dass das Geheimnis als einfache Zeichenkettenkonstante gespeichert wird, anstatt verschleiert zu werden.

3. Den Wert wiederherstellen und übermitteln:
- Kopieren Sie die von `getSecret()` zurückgegebene Zeichenkette aus der Dekompiler- oder Bytecode-Ausgabe.
- Falls Sie eine weitere schnelle Überprüfung wünschen, können Tools wie `strings wrongsecrets-java.jar` ebenfalls dabei helfen, lesbare Konstanten aufzudecken.
- Reichen Sie die wiederhergestellte Zeichenkette als Antwort ein.
