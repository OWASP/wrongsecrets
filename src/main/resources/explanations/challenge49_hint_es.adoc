La forma más sencilla de descifrar el PIN en este caso es realizar un ataque de fuerza bruta debido al rango limitado de valores posibles (de 0 a 99.999).

- Iterar sobre todos los PIN posibles (de 0 a 99.999).
- Para cada PIN, calcule su hash MD5 para obtener la clave de descifrado e intente descifrar el texto cifrado proporcionado.
- Si el texto descifrado es igual a `the answer`, has encontrado el PIN correcto.
