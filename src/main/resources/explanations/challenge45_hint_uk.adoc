Цю проблему можна вирішити, виконавши такі кроки:

1. Знайдіть секрет за допомогою командного рядка
- використовуйте `kubectl exec vault-0 -n vault -- vault kv get secret/wrongsecret` для пошуку даних.


2. Знайдіть секрет у сховищі, використовуючи зареєстрований кореневий токен:
- Під час налаштування середовища K8s скрипт повідомляє вам значення кореневого токена, як показано нижче:

    Key                  Value
    ---                  -----
    token                s.Jqka4lSy8ayQw2LFsvyAgnTI
    token_accessor       HEr9RYa3OcZNDOHeFRXIMYCV
    token_duration       ∞
    token_renewable      false
    token_policies       ["root"]
    identity_policies    []
    policies             ["root"]


- Використайте токен для входу у Vault, доступний на порту 8200
- Озирніться навколо: чи можете ви знайти місцезнаходження секрету в огляді секретів?

3. Знайдіть секрет як учасник SRE
- перейдіть до веб-інтерфейсу сховища
- увійдіть, використовуючи ім'я користувача "helper" та пароль "foo"
- знайти справжню таємницю.
