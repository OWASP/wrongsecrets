*Чому зберігання секретів у закритих задачах GitHub — погана ідея?*

Не додавайте секрети до задач. Видимість задачі залежить від налаштувань репозиторію, а закриття задачі не видаляє її історію чи копії. Натомість діліться необхідною інформацією через затверджений канал розкриття інформації з обмеженим доступом.

Перевірте проблемний контент перед публікацією. Якщо облікові дані розкрито, негайно скасуйте або замініть їх та видаліть розкритий контент, де це можливо.
