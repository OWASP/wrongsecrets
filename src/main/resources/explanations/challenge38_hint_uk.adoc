На відміну від інших проблем Git, цю неможливо вирішити за допомогою безлічі інструментів, які автоматично шукатимуть секрети, що витікають у репозиторії Git.

Спробуйте вирішити проблему, вручну переробивши метадані Git.

1. Клонуйте репозиторій - `git clone https://github.com/OWASP/wrongsecrets`.
2. Перейдіть до каталогу `cd wrongsecrets`
3. Отримати нотатки - `git fetch origin pass:['refs/notes/*:refs/notes/*']`
4. Перерахувати всі нотатки в репозиторії - `git notes`
5. Використовуючи посилання на нотатку, що відображається, покажіть нотатку — `git notes show [ref]` (для кожної нотатки буде показано 2 посилання, друге з яких — це посилання на нотатку)
