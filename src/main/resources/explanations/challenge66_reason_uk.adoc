*Чому обфускація — лише сповільнювач.*

Кодування, рефлексія та легка обфускація можуть ускладнити зворотний інжиніринг, але не створюють справжньої секретності. Виконуваний файл усе що містить усе необхідне для відновлення секрету.

Якщо застосунок може вивести секрет локально, рішучий атакувальник зможе зробити те саме. Захищай секрети, переносячи рішення про довіру та самі секрети на керовані серверні системи.
