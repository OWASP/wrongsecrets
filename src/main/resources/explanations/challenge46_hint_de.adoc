Diese Herausforderung kann auf folgende Weise gelöst werden:

- Ermitteln Sie die Daten des Sidecars, indem Sie die vom Vault Agent Sidecar erstellten Dateien untersuchen:
  1. Führen Sie `kubectl get pods -A` aus und suchen Sie nach dem Pod-Namen secret-challenge-xxx.
  2. Führen Sie `kubectl exec secret-challenge-xxx -c secret-challenge -n default -- cat vault/secrets/challenge46` aus, wobei `xxx` der Rest des zufällig generierten Pod-Namens ist, um die injizierten Secrets aus Vault auszugeben.

- Die Daten lassen sich ermitteln, indem man die Protokolle des Wrongsecrets-Pods überprüft, während `echo` aufgerufen wird:
  1. Führen Sie `kubectl get pods -A` aus und suchen Sie nach dem Pod-Namen secret-challenge-xxx.
  2. Führen Sie `kubectl logs secret-challenge-xxx` aus, wobei `xxx` der Rest des zufällig generierten Pod-Namens ist, um die Logs einschließlich der `echo`-Anweisung auszugeben.

Hinweis: Falls Sie dies in einer gehosteten Umgebung ausführen, in der Sie keinen Zugriff auf den Kubernetes-Cluster haben, bitten Sie den Organisator der gehosteten Lösung, die Befehle für Sie auszuführen und Ihnen die Ergebnisse zurückzugeben.
