=== Injection de modèle HashiCorp Vault, partie 2

Les secrets peuvent être récupérés depuis Vault à l'aide du conteneur sidecar Vault Agent (https://developer.hashicorp.com/vault/docs/platform/k8s/injector), qui s'exécute en parallèle de votre conteneur d'application principal. Ce sidecar peut injecter les secrets dans l'environnement de votre application.
Un développeur a tenté de comprendre pourquoi son injection Vault ne fonctionnait pas. Il a donc intégré les secrets « temporairement » dans le modèle Vault lui-même.
Parviendrez-vous à trouver le secret dissimulé dans le modèle du coffre-fort ?
