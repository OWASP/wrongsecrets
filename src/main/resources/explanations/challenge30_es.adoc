=== Otro secreto del cliente

El cliente recibe un valor aleatorio del servidor y debe devolverlo como respuesta para demostrar que es el servidor. Esto suele ocurrir, por ejemplo, cuando se necesita proporcionar un token de sesión. El token se genera aleatoriamente al iniciar el servidor, por lo que no se puede encontrar en el código. Pero, ¿qué sucede si lo almacenamos de forma insegura con el cliente?
