=== Mot de passe basé sur l'environnement Docker

Saviez-vous que vous pouvez également utiliser la variable d'environnement ENV dans les conteneurs Docker pour définir le mot de passe ? Quelle bonne idée de la partager avec tout le monde !

Vous pouvez facilement repérer le secret en observant comment les couches ont été construites ou en le détectant avec un outil comme https://github.com/goodwithtech/dockle[*Dockle*].
