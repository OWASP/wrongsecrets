Ce défi porte spécifiquement sur un secret stocké dans un binaire Swift sous forme de tableau de caractères.

Vous pouvez résoudre ce problème en utilisant les solutions alternatives suivantes :

1. Découvrez les secrets avec https://ghidra-sre.org/[Ghidra].
- Installez https://ghidra-sre.org/[Ghidra].
- Lancez-le avec `ghidraRun`.
- Chargez l'application `wrongsecrets-swift` dans Ghidra en choisissant un nouveau projet, puis importez le fichier et double-cliquez dessus.
- Autoriser Ghidra à analyser l'application.
- Recherchez la fonction `getSecret` - vous pouvez la rechercher dans l'arbre des symboles.
- Dans le code décompilé, trouvez le tableau de caractères qui constitue le secret.
- Autre solution : sur macOS, utilisez `nm -gUj wrongsecrets-swift | grep getSecret` puis `swift-demangle --expand "s5swift9getSecretSSyF"` pour trouver la fonction.

2. Découvrez les secrets avec https://www.radare.org[radare2].
- Installez https://www.radare.org[radare2] soit avec `brew install radare2` sur Mac, soit en suivant ces étapes : `git clone https://github.com/radareorg/radare2; cd radare2 ; sys/install.sh`
- Lancez l'analyse r2 avec `$ r2 -AAA wrongsecrets-swift`
- Recherchez des chaînes de caractères avec `iz | grep -i secret` ou `iz | grep -i "This"`.
- Sinon, recherchez la fonction `getSecret` : `afl | grep getSecret` puis imprimez la fonction avec `pdf @ <function_address>`.
- Examinez la construction du tableau de caractères dans le code décompilé ou désassemblé.

3. Découvrez les secrets avec https://binary.ninja [Binary Ninja] ou des outils similaires :
- Chargez le binaire et accédez à la fonction Swift modifiée `s5swift9getSecretSSyF`.
- Le secret est constitué d'un ensemble de caractères.

Vous ne souhaitez pas installer les outils ? Consultez le https://github.com/OWASP/wrongsecrets/tree/master?tab=readme-ov-file#want-to-play-but-are-not-allowed-to-install-the-tools[WrongSecrets Desktop container] !
