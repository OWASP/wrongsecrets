Цей челендж стосується, зокрема, хешів MD5 та SHA1 без використання солі. Чи їх неможливо зламати?

Ви можете вирішити цю проблему, використовуючи такі рішення:

1. Для першого хешу (MD5):
- Використовуйте такий інструмент, як Hashcat:
- Встановіть https://hashcat.net/hashcat/[Hashcat]
- Завантажте https://github.com/brannondorsey/naive-hashcat/releases/download/data/rockyou.txt[список паролів rockyou.txt]
- Запустіть Hashcat для хешу `hashcat -m 0 "2ab96390c7dbe3439de74d0c9b0b1767" /path/to/file/rockyou.txt`

2. Для другого хешу (SHA1):
- Використовуйте такий інструмент, як Hashcat:
- Встановіть https://hashcat.net/hashcat/[Hashcat]
- Завантажте https://github.com/brannondorsey/naive-hashcat/releases/download/data/rockyou.txt[список паролів rockyou.txt]
- Запустіть Hashcat для хешу `hashcat -m 100 "F3BBBD66A63D4BF1747940578EC3D0103530E21D" /path/to/file/rockyou.txt`

3. Для будь-якого з хешів:
- Скористайтеся онлайн-сервісом з розбиття хешів, який зробить всю важку роботу за вас:
- Відвідайте `https://crackstation.net/`
- Введіть хеш і натисніть "Зламати хеші"
