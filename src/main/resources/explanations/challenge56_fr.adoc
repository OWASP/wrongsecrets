=== Défi 56 : Trouvez le secret dans le cahier des charges du projet

Nous voulions voir si l'IA pouvait nous proposer un défi. Comme tout défi WrongSecrets, il devait comporter un « secret » divulgué quelque part. L'IA devait créer ce défi à partir d'un exemple de plan Agentic contenant des secrets.

Dans ce défi, votre tâche consiste à trouver un secret qui a été caché dans le fichier de documentation du plan d'agent du projet : https://github.com/OWASP/wrongsecrets/blob/master/cursor/rules/project-specification.mdc[`cursor/rules/project-specification.mdc`].

Le secret est dissimulé dans le fichier de spécification, sous forme d'exemple de valeur de configuration. Consultez attentivement la documentation : les secrets y sont souvent cachés, dissimulés dans des exemples de valeurs, de paramètres de configuration ou de données.

**Astuce :** Recherchez des références au « défi 56 » ou recherchez des valeurs de configuration suspectes qui pourraient être utilisées comme exemples.

Ce défi illustre comment des informations confidentielles peuvent parfois être dissimulées dans des documents ou des fichiers de spécifications, souvent négligés lors des audits de sécurité. Dans la pratique, il arrive que des développeurs laissent des identifiants de connexion dans la documentation à titre d'« exemples », identifiants qui finissent par être oubliés et jamais supprimés.

=== NOTE
Ce défi a été entièrement généré par l'IA et est donc très différent des autres défis de ce projet.
