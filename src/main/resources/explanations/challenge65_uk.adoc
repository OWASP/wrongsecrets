=== Приховування в бінарних файлах, частина 6: проста Java CLI

Прості рядки в Java CLI легко відновити після завантаження JAR-файлу. Чи зможеш ти знайти секрет, прихований у нашій простій Java CLI?

Щоб розв'язати завдання:

. Завантаж і перевір https://github.com/OWASP/wrongsecrets/raw/master/src/main/resources/executables/wrongsecrets-java.jar[wrongsecrets-java.jar].
. Декомпілюй JAR або перевір основний клас за допомогою декомпілятора Java, як-от CFR, JADX, IntelliJ IDEA чи `javap`.
. Знайди клас, який повертає секрет, і визнач простий рядок, вбудований у CLI.
. Коли відновиш точне значення секрету, надішли його в полі нижче або перевір командою `java -jar wrongsecrets-java.jar <твій відновлений секрет>`.
