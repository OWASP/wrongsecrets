=== Приховування у двійкових файлах, частина 6: простий інтерфейс командного рядка Java

Прості рядки всередині Java CLI легко відновити після завантаження JAR-файлу. Чи можете ви знайти секрет, прихований у нашому простому Java CLI?

Щоб вирішити це:

. Завантажте та перевірте https://github.com/OWASP/wrongsecrets/raw/master/src/main/resources/executables/wrongsecrets-java.jar[wrongsecrets-java.jar].
. Декомпілюйте JAR-файл або перевірте основний клас за допомогою декомпілятора Java, такого як CFR, JADX, IntelliJ IDEA або `javap`.
. Знайдіть клас, який повертає секрет, та визначте простий рядок, вбудований у CLI.
. Після того, як ви отримаєте точне значення секрету, ви можете надіслати його в поле нижче або перевірити його за допомогою `java -jar wrongsecrets-java.jar <your recovered secret>`.
