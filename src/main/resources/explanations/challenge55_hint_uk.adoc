Приватний ключ знаходиться всередині частини контейнера .ssh і в цьому випадку випадково передається до git ;-).

Ви можете знайти ключ таким чином:

1. отримання його з git у файлі [`.ssh/wrongsecrets.keys`]():
- Клонуйте репозиторій за допомогою `git clone https://github.com/OWASP/wrongsecrets`.
- Перейдіть до кореневого каталогу проекту та перейдіть до папки `.ssh` за допомогою cd та знайдіть файл `wrongsecrets.keys`.

2. отримання його з контейнера Docker:
- Запустіть контейнер локально за допомогою `docker run jeroenwillemsen/wrongsecrets:<TAGNAME-HERE>`
 - Знайдіть ідентифікатор контейнера, виконавши команду `docker ps` у наступному терміналі
 - Виконайте команду `docker exec -it <container id> sh`
 - перейдіть до /home/wrongsecrets/.ssh/
 - виконати `cat wrongsecrets.keys`
