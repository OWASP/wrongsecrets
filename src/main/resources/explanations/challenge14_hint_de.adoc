Diese Herausforderung lässt sich durch folgende alternative Lösungsansätze bewältigen:

Hinweis: Für diese Aufgabe müssen Sie https://www.keepassx.org/[Keepass(X)] auf Ihrem System installieren, um die kdbx-Datei zu öffnen. Alternativ können Sie die Lösung auch mithilfe des WrongSecrets Deskop unter https://github.com/OWASP/wrongsecrets?tab=readme-ov-file#want-to-play-but-are-not-allowed-to-install-the-tools finden.

1. Holen Sie sich die KeePass-Datei aus dem Docker-Container und öffnen Sie sie.
 - Schauen Sie in der Dockerfile nach, wohin die KeePass-Datei kopiert wurde.
 - Folgen Sie den Anweisungen unter https://docs.docker.com/engine/reference/commandline/cp/[der Docker-Dokumentation], um die Keepass-Datei vom Stammverzeichnis des Containers in Ihr lokales Dateisystem zu kopieren.
- Öffnen Sie die Datei mit KeepassX. Es erscheint eine Passwortabfrage.
- Überprüfen Sie zunächst den Code von `Challenge14.java` unter https://github.com/OWASP/wrongsecrets/blob/master/src/main/java/org/owasp/wrongsecrets/challenges/docker/Challenge14.java[github], um herauszufinden, wo das Passwort möglicherweise gespeichert ist. Öffnen Sie anschließend die Datei `Application.properties` im Ordner `src/resources` unter https://github.com/OWASP/wrongsecrets[*Ziel-Repository*] und prüfen Sie die Eigenschaft, die das KeePass-Passwort enthält.
- Öffnen Sie nun die KeePass-Datei mit dem gefundenen Passwort. Der Inhalt sollte Ihnen die Zugangsdaten für Alibaba Cloud liefern. Das ist die Lösung!
2. Holen Sie sich die Keepass-Datei aus den Testressourcen: Wir waren so dumm, die gleiche Datei in `src/test/resources/alibabacreds.kdbx` abzulegen, sodass Sie diese Datei ebenfalls öffnen können.
 - Schau dir das Projekt mit Git an und öffne die Datei oder lade sie von https://github.com/OWASP/wrongsecrets/blob/master/src/test/resources/alibabacreds.kdbx[Github] herunter.
 - Öffnen Sie die Datei mit KeepassX. Es erscheint eine Passwortabfrage.
 - Überprüfen Sie zunächst den Code von `Challenge14.java` unter https://github.com/OWASP/wrongsecrets/blob/master/src/main/java/org/owasp/wrongsecrets/challenges/docker/Challenge14.java[github], um herauszufinden, wo das Passwort möglicherweise gespeichert ist. Öffnen Sie anschließend die Datei `Application.properties` im Ordner `src/resources` unter https://github.com/OWASP/wrongsecrets[*Ziel-Repository*] und prüfen Sie die Eigenschaft, die das KeePass-Passwort enthält.
- Öffnen Sie nun die KeePass-Datei mit dem gefundenen Passwort. Der Inhalt sollte Ihnen die Zugangsdaten für Alibaba Cloud liefern. Das ist die Lösung!
