=== Копія Docker та робочий каталог

Іноді великі частини локальної файлової системи копіюються до контейнера, щоб вони були доступні в контейнері для зручності автора.

У цьому челенджі ми також виконали КОПІЮВАННЯ та сховали там ключ. Зверніть увагу, що ключ змінюється з кожним поколінням контейнера Docker, тому краще швидко його витягнути та використати :).

Спробуйте https://github.com/deepfence/SecretScanner[*deepfenceio/secretscanning*], `docker history` образу або просто `docker exec` для запущеного контейнера.
