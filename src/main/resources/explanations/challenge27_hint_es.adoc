Puedes encontrar la entrada correcta para el método de adivinación mediante:

1. Comparación de hashes:
- Consulta el contrato en el explorador https://etherscan.io/[Etherscan].
- Extraiga el hash del almacenamiento del contrato.
- Revisa las transacciones y luego abre la pestaña de entradas y decodifícalas como UTF-8.
- Comparar los hashes de las entradas de las transacciones con el valor hash almacenado.
