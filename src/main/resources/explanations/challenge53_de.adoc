=== Debugging eines Container-Lecks

Moderne Cloud-Umgebungen nutzen häufig Debugging-Tools zur Fehlerbehebung in laufenden Anwendungen. Werden Debugging-Funktionen jedoch in der Produktionsumgebung nicht deaktiviert, können sensible Informationen offengelegt werden.

Eine Kubernetes-Bereitstellung wurde falsch konfiguriert [challenge53](https://github.com/OWASP/wrongsecrets/blob/master/k8s/challenge53/secret-challenge53.yml). Dadurch können Entwickler einen Debugging-Container an eine laufende Anwendung anhängen. In diesem Container befindet sich eine Binärdatei, die ein Geheimnis im Speicher hält. Normalerweise wäre dieses Geheimnis geschützt, aber durch den Debugging-Zugriff ist es nun auslesbar.

Kannst du das Geheimnis lüften?
