=== Витік секретів у Dev Container

Контейнери розробки (Dev Containers) дозволяють командам визначати відтворювані середовища розробки за допомогою інструментів контейнеризації, таких як VS Code Remote - Containers та GitHub Codespaces. Укладаючи інструменти, середовища виконання та залежності в `.devcontainer/devcontainer.json`, розробники можуть почати роботу без встановлення складних локальних програмних стеків.

Однак розробники часто роблять помилку, вбудовуючи чутливі токени, паролі, ключі API або облікові дані для доступу до приватного реєстру безпосередньо в `.devcontainer/devcontainer.json` (наприклад, у `containerEnv`, `remoteEnv` або скриптах життєвого циклу) і додаючи їх до системи керування версіями.

Щоб вирішити це завдання:

. Перегляньте файл конфігурації devcontainer https://github.com/OWASP/wrongsecrets/tree/master/.devcontainer/devcontainer.json[`.devcontainer/devcontainer.json`] у репозиторії проєкту або подивіться фрагмент конфігурації в інтерфейсі.
. Визначте витік `DEVCONTAINER_SECRET` або токен, визначений у середовищі контейнера.
. Надішліть знайдений секрет у полі введення нижче.
