=== Витік секретної інформації з контейнера розробника

Контейнери розробки (Dev Containers) дозволяють командам визначати відтворювані середовища розробки за допомогою інструментів контейнеризації, таких як VS Code Remote - Containers та GitHub Codespaces. Інкапсулюючи інструменти, середовища виконання та залежності в `.devcontainer/devcontainer.json`, розробники можуть розпочати роботу без встановлення складних локальних програмних стеків.

Однак розробники часто помиляються, вбудовуючи конфіденційні токени, паролі, ключі API або приватні облікові дані для доступу до реєстру безпосередньо в `.devcontainer/devcontainer.json` (наприклад, у `containerEnv`, `remoteEnv` або скрипти життєвого циклу) та передаючи їх до системи контролю версій.

Щоб вирішити цю проблему:

. Перевірте файл конфігурації https://github.com/OWASP/wrongsecrets/tree/master/.devcontainer/devcontainer.json[`.devcontainer/devcontainer.json`] devcontainer у репозиторії проекту або перегляньте фрагмент конфігурації в інтерфейсі користувача.
. Визначте витік `DEVCONTAINER_SECRET` або токена, визначеного в середовищі контейнера.
. Введіть знайдений секрет у поле введення нижче.
