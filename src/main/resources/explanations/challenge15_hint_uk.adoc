Ви можете вирішити цю проблему за допомогою таких альтернативних рішень:

1. Отримайте секрет зі старих комітів за допомогою Trufflehog
- встановіть https://github.com/feeltheajf/trufflehog3[trufflehog3], виконавши команду `pip3 install trufflehog3`, для чого потрібно встановити python3 та pip
- запустіть `trufflehog3 https://github.com/OWASP/wrongsecrets` та подивіться на результат: ви повинні знайти 3 `aws_secret_access_key`, один з яких і є рішенням!
2. Отримайте секрет, «використовуючи шифрування» завдання, оскільки зашифровані матеріали все ще знаходяться в класі Java (Зверніть увагу, що це більш складний тест, який вимагає певних навичок Java).
- Знайдіть контейнер, який використовується для виконання цього завдання.
- Розшифруйте зашифрований текст для Завдання 15
- Клонуйте проєкт локально та запустіть його локально, дотримуючись інструкцій на сторінці https://github.com/OWASP/wrongsecrets#notes-on-development[Readme.md].
- https://www.jetbrains.com/help/idea/debugging-your-first-java-application.html[Налагодження] проекту, встановивши точку зупинки на початку методу `quickDecrypt`.
- Перезапишіть значення cipherText шифротекстом, який ви витягли на кроці 2, і тепер знайдіть відкритий текст.
