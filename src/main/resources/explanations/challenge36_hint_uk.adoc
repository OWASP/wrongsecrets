Цю проблему можна вирішити, отримавши рядки, що зберігаються в регістрах. Ви можете використовувати будь-який інструмент налагодження. Ми покажемо вам, як вирішити проблему за допомогою GDB та Radare2 у наступних інструкціях.
Зверніть увагу, що ми показуємо це лише для виконуваного файлу Windows. Усі інші виконувані файли матимуть інше розташування, але суть вправи буде схожою.

Щоб виконати завдання за допомогою GDB, відкрийте термінал і введіть:

1. `gdb -q wrongsecrets-advanced-c-windows.exe` для відкриття GDB та завантаження виконуваного файлу
2. `disas main`, для дизасемблювання функції `main`, яка є точкою входу в програму.
3. `b execute` для встановлення точки зупинки у функції `execute`.
4. `set args 1234567812345678` для встановлення аргументів програми. Ви можете встановити випадковий рядок довжиною 16 символів.
5. Натисніть `r`, щоб запустити програму. Це може не спрацювати на MacOS, у такому випадку зверніться до https://sourceware.org/gdb/wiki/PermissionsDarwin[gdb wiki]
6. `disas execute` для дизасемблювання функції `execute`
7. `b compare` для встановлення точки зупинки у функції `compare`. Щоб отримати ключ:
- a. `b get_key` для встановлення точки зупинки у функції `get_key`
- b. `disas get_key` для дизасемблювання функції `get_key`
- c. Знайдіть інструкцію `movabs xxx, %rax` та скопіюйте шістнадцяткові значення без 0x.
- d. Повторіть це для інструкції `movabs xxx, %rdx`
Потім нам потрібно перевірити порядок байтів архітектури процесора, щоб розшифрувати правильний шифр. Для цього відкрийте термінал Python3 і введіть:
- наприклад, `from sys import byteorder`
- f. `print(byteorder)`
- g. Якщо порядок байтів дорівнює `little`, https://blockchain-academy.hs-mittweida.de/litte-big-endian-converter/[натисніть тут], щоб конвертувати з little (літнього) у big (великий) ендіан.

8. Скопіюйте кожен рядок та об'єднайте два рядки після перетворення. Приклад:
- a. `big_endian_a = '69676F74616C6C74'`
- b. `big_endian_b = '68656B6579737373'`
- c. `big_endian_result = '69676F74616C6C7468656B6579737373'`, і ви отримали ключ для розшифрування. Вийдіть з програми та відкрийте її знову, щоб отримати секретне повідомлення.

9. `b get_secret_message` для встановлення точки зупинки у функції `get_secret_message`
- a. `c` для продовження виконання програми
- b. `disas get_secret_message` для дизасемблювання функції `get_secret_message`
- c. Знайдіть інструкцію `movabs xxx, %rax` та скопіюйте шістнадцяткові значення без 0x.
- d. Повторіть це для інструкції `movabs xxx, %rdx`
- e. Перевірте порядковість байтів архітектури вашого процесора, використовуючи кроки `7.e`, `7.f` та `7.g`. В результаті: `big_endian_result = 'E49F2F331A9A251974E1BA7F724C3B7F'`
10. Завантажте папку `decrypt`, відкрийте термінал і введіть:
- `gcc decrypt.c -o decrypt` для компіляції коду, або ви можете скомпілювати декод відповідно до вашої операційної системи.

11. `./decrypt E49F2F331A9A251974E1BA7F724C3B7F 69676F74616C6C7468656B6579737373` і у вас є секретний ключ, який є відповіддю на завдання.
