Diese Aufgabe befasst sich speziell mit einem Geheimnis in einer C++-Binärdatei.

Diese Herausforderung lässt sich mit den folgenden alternativen Lösungsansätzen bewältigen:

1. Entdecken Sie die Geheimnisse mit https://ghidra-sre.org/[Ghidra].
- Installieren Sie https://ghidra-sre.org/[Ghidra].
- Starten Sie es mit `ghidraRun`.
- Laden Sie die Anwendung `wrongsecrets-cplus` in Ghidra, indem Sie ein neues Projekt auswählen, dann die Datei importieren und anschließend darauf doppelklicken.
- Erlauben Sie Ghidra, die Anwendung zu analysieren.
- Suche nach dem Geheimnis: Gehe links auf `Functions` und wähle `__Z6secretv()`. Das Geheimnis wird nun rechts angezeigt. Es handelt sich um einen in C++ geschriebenen String, der in einer anderen Klasse (`SecretContainer`) gekapselt ist.
- Suchen Sie nach demselben Geheimnis, das als Zeichenarray „versteckt“ ist: Gehen Sie links auf `Functions` und wählen Sie `__Z7secret2v()` aus. Rechts sehen Sie die Funktion. Klicken Sie nun auf das Ergebnis der Funktion unter `__ZZ7secret2vE6harder`. Das Ergebnis wird nun in der Listenansicht angezeigt.
- Alternativ: Wenn Sie die Anwendung mit Ghirda analysiert haben, suchen Sie in allen Blöcken nach Zeichenketten und sehen Sie, ob Sie das Geheimnis entdecken können ;-).

2. Entdecken Sie die Geheimnisse mit https://www.radare.org[radare2].
- Installieren Sie https://www.radare.org[radare2] entweder mit `brew install radare2` auf einem Mac oder folgen Sie diesen Schritten: `git clone https://github.com/radareorg/radare2; cd radare2 ; sys/install.sh`
- Starten Sie die r2-Analyse mit `$ r2 -A wrongsecrets-cplus`
- Verwenden Sie den Befehl `pdf @ sym.secret__`, um die disassemblierte Ausgabe der Funktion anzuzeigen, die das Geheimnis zurückgibt.
- Verwenden Sie den Befehl `pdf @ sym.secret2__`, um die disassemblierte Ausgabe der Funktion anzuzeigen, die secret2 zurückgibt.

Sie möchten die Tools nicht installieren? Dann schauen Sie sich den https://github.com/OWASP/wrongsecrets/tree/master?tab=readme-ov-file#want-to-play-but-are-not-allowed-to-install-the-tools[WrongSecrets Desktop container] an!
