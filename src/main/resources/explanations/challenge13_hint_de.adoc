1. Extrahiere das Geheimnis mithilfe von GitHub Actions. Beachte, dass in der aktuellen Projektkonfiguration die vom Eigentümer/Mitwirkenden ausgelöste Aktion das Geheimnis enthält. Dies ist nicht der Fall, wenn du es mit Forks versuchst. Lass uns die Schritte besprechen:
- Melde dich mit deinem eigenen Konto bei GitHub an.
- Gehe zu https://github.com/OWASP/wrongsecrets/actions und wähle `Get the challenge code 13` aus.
- Schau dir die neueste Version an, die von einem der Eigentümer oder Mitarbeiter erstellt wurde.
- Nimm den letzten Durchlauf, bei dem das Geheimnis Base64-kodiert ist. Kopiere das Base64-kodierte Ergebnis und dekodiere es zweimal.
- Gib die dekodierte Lösung als Antwort ein.
