Dies ist eine Dokumentationsherausforderung, die durch einen Besuch des GitHub Advisory gelöst werden kann.

1. Ermittle den Schlüssel mithilfe der GitHub-Sicherheitswarnung.
- Gehe zu https://github.com/OWASP/wrongsecrets/security/advisories/GHSA-vv4g-7gjw-fvqw[der Sicherheitswarnung].
- Den Google API-Schlüssel finden.
- Kopiere es in das Antwortfeld.

2. Beachte die Sicherheitshinweise von GitHub.
- Gehe zu https://github.com/OWASP/wrongsecrets/security/advisories/GHSA-vv4g-7gjw-fvqw[der Sicherheitswarnung].
- Ermittle die betroffene Version (1.6.8RC1).
- Öffne den Tag unter https://github.com/OWASP/wrongsecrets/tree/1.6.8RC1[Github].
- Finde den Google API-Schlüssel in Aufgabe 35.
- Kopiere es in das Antwortfeld.
