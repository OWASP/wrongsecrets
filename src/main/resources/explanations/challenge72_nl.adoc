=== Uitdaging 72: Vind het geheim in het transcript van de AI-codeagent

AI-codeagents zoals Codex, Claude Code en Cursor lezen bestanden, voeren commando's uit en maken gedetailleerde sessietranscripts. Wanneer een developer een agent vraagt om een probleem met een deployment te debuggen, kan de agent configuratiebestanden met geheimen lezen en die waarden in zijn sessie-uitvoer terugkaatsen.

Deze applicatie bevat een Codex-sessietranscript waarin een developer de agent vroeg om een mislukte staging-deployment te onderzoeken. Het transcript legt vast hoe de agent een bestand `.env.staging` leest en de inhoud ervan uitvoert — inclusief de deploy-token — als onderdeel van een normale debugworkflow.

Download het transcript van link:/challenges/challenge-72/codex-session-transcript.md[`/challenges/challenge-72/codex-session-transcript.md`] en zoek de staging-deploy-token die tijdens de sessie is blootgesteld.

De bron is ook beschikbaar via link:https://github.com/OWASP/wrongsecrets/blob/master/src/main/resources/challenges/challenge-72/codex-session-transcript.md[`src/main/resources/challenges/challenge-72/codex-session-transcript.md`].

[NOTE]
====
Het token komt vanzelfsprekend in de uitvoer van het transcript terecht — de agent had niet de bedoeling het te lekken, hij las simpelweg een bestand als onderdeel van zijn debugproces.
====
