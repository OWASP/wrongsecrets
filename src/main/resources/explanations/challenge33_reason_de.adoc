*Warum Sie beim Migrieren von Geheimnissen vorsichtig sein sollten*

Wenn Sie ein Kubernetes-Secret aktualisieren und in ein anderes Format migrieren, sind die ursprünglichen Daten Teil der Metadaten, die in der ursprünglichen Konfiguration erfasst wurden.
Die Migration von Geheimnissen in „etwas anderes“ sollte auch einen Rotationsschritt beinhalten, um sicherzustellen, dass der ältere (weniger gut geschützte) Wert nun unbrauchbar ist.
