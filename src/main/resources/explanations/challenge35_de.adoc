=== Meldung von Schwachstellen

Ein Sicherheitsforscher hat einen Google-API-Schlüssel gefunden und zusammen mit dem Projektleiter https://github.com/commjoen[@commjoen] eine Sicherheitswarnung auf GitHub erstellt. Der einzige Fehler von @commjoen war, den API-Schlüssel in der Warnung zu veröffentlichen. Kannst du den Schlüssel entdecken?
