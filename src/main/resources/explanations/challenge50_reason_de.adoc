*Warum die Verwendung von Binärdateien zum Verbergen eines Geheimnisses einen Angreifer nur aufhält.*

Dank kostenloser Reverse-Engineering-Anwendungen wie ILSpy ist kaum noch etwas sicher. Jeder, der die ausführbare Datei in solchen Tools laden kann, kann problemlos Daten sammeln und Geheimnisse in deinem Binärcode aufdecken.

Die Verschlüsselung des Geheimnisses mit einem im Binärcode eingebetteten Schlüssel und andere lustige Rätsel verzögern einen Angreifer und machen es schlichtweg unterhaltsamer, das Geheimnis zu finden. Beachte, dass das Geheimnis, falls es von der ausführbaren Datei benötigt wird, letztendlich im Speicher verfügbar sein muss.

Muss das Geheimnis weiterhin in der Binärdatei enthalten sein? Stelle sicher, dass es nur nach erfolgreicher Authentifizierung an einem Server remote abgerufen werden kann.
