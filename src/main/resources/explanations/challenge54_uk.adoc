=== .gitignore Секретний виклик

Файли `.gitignore` допомагають уникнути випадкового додавання конфіденційних або нерелевантних даних до системи керування версіями. Однак іноді розробники помилково додають конфіденційні дані або секрети як коментарі або приховані записи в `.gitignore`.

У цьому челенджі розробник залишив зашифрований секретний код у коментарі до файлу `.gitignore`. Незважаючи на те, що він зашифрований, він показує, як легко забути важливі секретні дані у доступних місцях.

Ваша мета — знайти та розшифрувати цю забуту таємницю.

==== Примітка
Секрет зашифровано за допомогою AES-256-CBC та IV. Використайте ключ, знайдений у файлі ".gitignore", щоб розшифрувати його.
Ми використовували таку команду для шифрування:

Баш
echo -n "<you will have to find out>" | openssl enc -aes-256-cbc -K <you will have to find out> \
  -iv 30313233343536373839616263646566 \
  -nosalt -base64 -e
```
