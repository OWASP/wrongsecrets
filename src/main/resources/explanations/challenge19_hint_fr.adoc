Ce défi consiste spécifiquement à examiner un secret dans un binaire C

Vous pouvez résoudre ce problème en utilisant les solutions alternatives suivantes :

1. Découvrez les secrets avec https://ghidra-sre.org/[Ghidra].
- Installez https://ghidra-sre.org/[Ghidra].
- Lancez-le avec `ghidraRun`.
- Chargez l'application `wrongsecrets-c` dans ghidra en choisissant un nouveau projet, puis importez le fichier et double-cliquez dessus.
- Autoriser Ghidra à analyser l'application.
- Pour trouver le secret : allez dans `Functions` à gauche, puis sélectionnez `_secret`. Le secret s’affiche alors à droite. Il s’agit d’une chaîne de caractères en C.
- Recherchez le même secret, « caché » sous forme de tableau de caractères : dans le menu de gauche, cliquez sur `Functions`, puis sélectionnez `_secret2`. Vous constaterez qu’une étiquette s’affiche à droite. Ouvrez ensuite `Labels` dans le menu de gauche, sélectionnez l’étiquette renvoyée par `_secret2` (`_secret2.label`) et vous trouverez la réponse au centre. Il s’agit d’un tableau de caractères en C.

2. Découvrez les secrets avec https://www.radare.org[radare2].
- Installez https://www.radare.org[radare2] soit avec `brew install radare2` sur Mac, soit en suivant ces étapes : `git clone https://github.com/radareorg/radare2; cd radare2 ; sys/install.sh`
- Lancez l'analyse r2 avec `$ r2 -A wrongsecrets-c`
- Filtrer les fonctions par le terme `secret` à l'aide d'afl : `afl~secret`, obtenir la liste des fonctions
- Utilisez la commande `pdf @ sym._secret` pour afficher le résultat désassemblé de la fonction qui renvoie le secret.
- Utilisez la commande `pdf @ sym._secret2` pour afficher le résultat désassemblé de la fonction qui renvoie secret2


Vous ne souhaitez pas installer les outils ? Consultez le https://github.com/OWASP/wrongsecrets/tree/master?tab=readme-ov-file#want-to-play-but-are-not-allowed-to-install-the-tools[WrongSecrets Desktop container] !
