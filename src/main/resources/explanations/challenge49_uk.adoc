=== Злом шифрування AES за допомогою слабкого ключа MD5

Уявіть, що ви аналітик з безпеки, який досліджує мобільний додаток, що обробляє конфіденційну інформацію. Ви виявляєте, що розробник використовує шифрування AES для захисту секрету, але замість надійної функції виведення ключів (KDF) він покладається на незахищений алгоритм MD5 для отримання ключів шифрування з простого числового PIN-коду.

Ви отримали зашифрований рядок: `k800mdwu8vlQoqeAgRMHDQ==`. Ви знаєте, що цей рядок, після розшифрування, розкриває текст `the answer`.

Ключ, який використовується для AES-шифрування, виводиться шляхом хешування MD5 PIN-коду, який є числом від 0 до 99999. Ваше завдання — знайти правильний PIN-код, який використовувався для отримання ключа шифрування, та розшифрувати секрет.
