=== Секрети смарт-контрактів, частина 3

Наш розробник смарт-контракту став дещо розумнішим і зберіг у своєму контракті лише хешований секрет. Потім він перевіряє вхідні дані з цим хешем, щоб перевірити, чи повертає транзакція значення true чи false. Він впевнений, що оскільки секрет ніколи не зберігається у внутрішньому стані контракту, його неможливо знайти.

У цьому завданні вам потрібно знайти правильний секрет, метод вгадування якого з контракту `0x8318d477f4BCae5a80BEA22E3c040cf8BaaFFe8B` у тестовій мережі Goerli EVM повертає значення true.
