Цю проблему можна вирішити, використовуючи такі способи:

- Розшифруйте запечатаний секрет за допомогою доступного закритого ключа, знайденого в репозиторії:
  1. Клонуйте репозиторій, що містить файли завдання.
  2. Знайдіть файл `sealed-challenge48.json` у репозиторії.
  3. Знайдіть у репозиторії незашифрований файл закритого ключа з назвою `main.key`.
  4. Використайте інструмент `kubeseal` для розшифрування запечатаного секрету:
     ``
     kubeseal --recovery-unseal --recovery-private-key k8s/main.key < k8s/sealed-challenge48.json > unsealed-secret.yaml
     ``
  5. `unsealed-secret.yaml` — це unsealed secret, закодований у base64, нам потрібно його розшифрувати, і отриманий текст буде відповіддю.

- Отримайте доступ до секрету безпосередньо:
  1. маючи доступ до кластера, виконайте команду `kubectl get secret challenge48secret -o yaml`
  2. розшифруйте секрет.


Примітка: Переконайтеся, що у вас є дійсна конфігурація Kubernetes та доступ до кластера Kubernetes. Якщо ви запускаєте це в розміщеному середовищі, де у вас немає прямого доступу до кластера Kubernetes, попросіть організатора розміщеного рішення виконати команди для вас і повернути результати.
