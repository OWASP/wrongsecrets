Ви можете знайти правильні вхідні дані для методу вгадування таким чином:

1. Порівняння хешів:
- Знайдіть контракт у браузері https://etherscan.io/[Etherscan].
- Витягніть хеш зі сховища контракту.
- Перегляньте транзакції, потім відкрийте вкладку вхідних даних та розшифруйте їх як UTF-8.
- Порівняйте хеші вхідних даних з транзакцій зі збереженим хеш-значенням.
