=== Se cacher dans les binaires, partie 4 : le binaire Rust

Tout comme on peut dissimuler des secrets dans une application écrite en C, c'est possible en Rust. Cependant, Ghidra n'est pas très performant pour l'analyse de Rust par défaut… Parviendrez-vous à trouver le secret dans notre binaire ?

Démystifions le mythe selon lequel « les secrets sont difficiles à trouver dans les applications compilées natives » pour Rust : pouvez-vous trouver le secret dans https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-rust[wrongsecrets-rust] (ou https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-rust-arm[wrongsecrets-rust-arm], https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-rust-linux[wrongsecrets-rust-linux]) ?

Essayez de télécharger le fichier binaire et de l'exécuter localement (par exemple `./wrongsecrets-rust<theversion you need> <your answer>`).
