Diese Herausforderung können Sie mit den folgenden Schritten lösen:

1. Überprüfen Sie die Konfigurationsdatei des Entwicklungscontainers:
- Öffnen Sie die Datei `.devcontainer/devcontainer.json` im Stammverzeichnis des [Repositorys](https://github.com/OWASP/wrongsecrets/tree/master/.devcontainer).
- Suchen Sie nach den Abschnitten `containerEnv` oder `remoteEnv`, in denen Umgebungsvariablen definiert sind.

2. Überprüfen Sie die laufende Containerumgebung:
- Klonen Sie das Repository auf Ihren Computer.
- Öffnen Sie das Projekt in einem Entwicklungscontainer:
  . In VS Code: Drücken Sie Strg+Umschalt+P (oder Cmd+Umschalt+P unter macOS) -> wählen Sie „Entwicklungscontainer: Im Container neu öffnen“ (oder klicken Sie auf die Eingabeaufforderung in der unteren linken Ecke).
  . Klicken Sie in IntelliJ IDEA auf das Popup „Im Entwicklungscontainer öffnen“.
- Sobald das Projekt im Entwicklungscontainer geöffnet ist, überprüfen Sie die Umgebungsvariablen mit `printenv DEVCONTAINER_SECRET` oder `echo $DEVCONTAINER_SECRET`.
