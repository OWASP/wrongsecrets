=== Les secrets des contrats intelligents, partie 2

Notre développeur de contrats intelligents s'est rendu compte qu'il avait écrit un secret dans la chaîne et l'a réécrit par-dessus.

Dans ce défi, vous devez lire la variable nommée secret du contrat `0xCe793D588cd1Ee091290b4A1aE1D586B2a748eB4` sur le réseau de test Goerli EVM tel qu'il était avant qu'il ne soit modifié.
