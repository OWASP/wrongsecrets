*Pourquoi utiliser des binaires pour cacher un secret ne fera que retarder un attaquant.*

Avec de magnifiques applications gratuites d'ingénierie inverse comme Ghidra, peu de choses restent sûres. Quiconque peut charger l'exécutable dans Ghidra ou Radare2 peut facilement commencer une reconnaissance et trouver des secrets dans votre binaire Swift.

Les binaires Swift, bien qu'ils utilisent le name mangling (vous pouvez utiliser `swift-demangle` pour dé-mangler les noms de symboles Swift), restent susceptibles d'ingénierie inverse. Les secrets stockés sous forme de tableaux de caractères ou de littéraux de chaîne peuvent être trouvés dans la section de données du binaire.

Chiffrer le secret avec une clé intégrée au binaire, et d'autres petits puzzles, retarde effectivement un attaquant et rend la découverte du secret amuse. Notez que si le secret doit être utilisé par l'exécutable, il doit finalement se trouver en mémoire, prêt à être exécuté.

Vous avez encore besoin d'un secret dans le binaire ? Assurez-vous qu'il ne puisse être récupéré à distance qu'après vous être authentifié auprès d'un serveur.
