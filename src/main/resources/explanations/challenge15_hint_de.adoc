Diese Herausforderung lässt sich durch folgende alternative Lösungsansätze bewältigen:

1. Ermitteln Sie das Geheimnis aus älteren Commits mithilfe von Trufflehog.
- Installieren Sie https://github.com/feeltheajf/trufflehog3[trufflehog3], indem Sie `pip3 install trufflehog3` ausführen. Dies erfordert die Installation von Python 3 und pip.
- Führen Sie `trufflehog3 https://github.com/OWASP/wrongsecrets` aus und sehen Sie sich die Ausgabe an: Sie sollten 3 `aws_secret_access_key` finden, einer davon ist die Lösung!
2. Erhalten Sie das Geheimnis, indem Sie die Verschlüsselung der Aufgabe nutzen, da sich die verschlüsselten Materialien noch in der Java-Klasse befinden (Hinweis: Dies ist ein fortgeschrittenerer Test und erfordert Java-Kenntnisse).
- Finde den Container, der dir diese Herausforderung anbietet.
- Extrahieren Sie den Chiffretext für Herausforderung 15
- Klonen Sie das Projekt lokal und führen Sie es lokal gemäß den Anweisungen unter https://github.com/OWASP/wrongsecrets#notes-on-development[Readme.md] aus.
- https://www.jetbrains.com/help/idea/debugging-your-first-java-application.html[Debuggen] Sie das Projekt, indem Sie einen Haltepunkt am Anfang der Methode `quickDecrypt` setzen.
- Überschreiben Sie den Wert von cipherText mit dem in Schritt 2 extrahierten Chiffretext und suchen Sie nun den Klartext.
