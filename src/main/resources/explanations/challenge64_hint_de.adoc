Diese Aufgabe befasst sich speziell mit einem Geheimnis, das in einer Swift-Binärdatei als Zeichenkette gespeichert ist.

Diese Herausforderung lässt sich mit den folgenden alternativen Lösungsansätzen bewältigen:

1. Entdecken Sie die Geheimnisse mit https://ghidra-sre.org/[Ghidra].
- Installieren Sie https://ghidra-sre.org/[Ghidra].
- Starten Sie es mit `ghidraRun`.
- Laden Sie die Anwendung `wrongsecrets-swift` in Ghidra, indem Sie ein neues Projekt auswählen, dann die Datei importieren und anschließend darauf doppelklicken.
- Erlauben Sie Ghidra, die Anwendung zu analysieren.
- Suchen Sie nach der Funktion `getSecret` - Sie können sie im Symbolbaum finden.
- Finde im dekompilierten Code das Array von Zeichen, aus denen das Geheimnis besteht.
- Alternativ: Unter macOS können Sie mit `nm -gUj wrongsecrets-swift | grep getSecret` und anschließend mit `swift-demangle --expand "s5swift9getSecretSSyF"` die Funktion finden.

2. Entdecken Sie die Geheimnisse mit https://www.radare.org[radare2].
- Installieren Sie https://www.radare.org[radare2] entweder mit `brew install radare2` auf einem Mac oder folgen Sie diesen Schritten: `git clone https://github.com/radareorg/radare2; cd radare2 ; sys/install.sh`
- Starten Sie die r2-Analyse mit `$ r2 -AAA wrongsecrets-swift`
- Suche nach Zeichenketten mit `iz | grep -i secret` oder `iz | grep -i "This"`.
- Alternativ können Sie nach der Funktion `getSecret` suchen: `afl | grep getSecret` und anschließend die Funktion mit `pdf @ <function_address>` ausgeben.
- Untersuchen Sie die Konstruktion des Zeichenarrays im dekompilierten oder disassemblierten Code.

3. Finde die Geheimnisse mit https://binary.ninja[Binary Ninja] oder ähnlichen Tools:
- Laden Sie die Binärdatei und navigieren Sie zur Swift-Mangled-Funktion `s5swift9getSecretSSyF`.
- Das Geheimnis setzt sich aus einer Reihe von Zeichen zusammen.

Sie möchten die Tools nicht installieren? Dann schauen Sie sich den https://github.com/OWASP/wrongsecrets/tree/master?tab=readme-ov-file#want-to-play-but-are-not-allowed-to-install-the-tools[WrongSecrets Desktop container] an!
