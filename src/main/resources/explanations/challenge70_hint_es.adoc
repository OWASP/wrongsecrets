Descarga y descomprime el paquete de habilidades exportado:

----
curl -sO http://localhost:8080/skills/claude/incident-reporter.zip
unzip incident-reporter.zip
----

El archivo `SKILL.md` solo apunta al cargador incluido. Abra `incident-reporter/scripts/upload_report.py` y examine `UPLOAD_TOKEN_B64`.

Ese valor aún no es la respuesta: el autor lo codificó en base64 para evitar que el escáner de secretos emitiera una alerta. Decodifícalo, por ejemplo con `base64 -d`, y envía el token decodificado.
