Vous pouvez relever ce défi grâce aux solutions alternatives suivantes :

1. Trouvez le secret dans AWS Secrets Manager (c'est la méthode la plus simple, essayez l'autre :) ) :
- Connectez-vous à AWS https://console.aws.com/[Console] avec le compte avec lequel vous avez créé la configuration WrongSecrets.
- Accédez à AWS Secrets Manager
- Récupérez les données de wrongsecrets2

2. Découvrez le secret en exécutant dans le POD
- Assurez-vous d'avoir installé Kubectl comme indiqué dans le fichier README.MD et que kubectl est configuré pour envoyer des commandes au bon cluster.
- Maintenant, exécutez `kubectl get pods`. Vous verrez alors tous les pods actifs dans l'espace de noms actuel, qui est normalement `default` pour cette application (sauf indication contraire de votre administrateur/formateur).
- Pour votre instance du pod WrongSecrets, exécutez `kubectl exec -it secret-challenge-<rest of the name of the pod from the prev.step> -- sh`.
- Examinez maintenant les données que vous pouvez trouver dans `/mnt/secrets-store`
