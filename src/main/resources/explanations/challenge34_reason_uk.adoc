*Чому функції виведення ключів небезпечні при використанні жорстко закодованих значень*

Функції виведення ключа (KDF) є детермінованими. Це означає, що вони завжди повертатимуть однаковий вихід для заданого вхідного значення. Отже, якщо параметри жорстко закодовані, будь-хто з доступом до коду може запустити KDF із зазначеними параметрами та отримати ключ.

Використовуйте KDF, такий як Argon2id, з унікальною випадковою сіллю та відповідними параметрами вартості, під час отримання ключа з пароля. Для ключів, згенерованих машиною, використовуйте криптографічно захищений генератор випадкових чисел замість KDF та зберігайте ключ окремо від зашифрованих даних.
