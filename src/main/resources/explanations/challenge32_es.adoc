=== Un secreto subido a una aplicación LLM (modelo de lenguaje grande)

La IA ha llegado para quedarse. Puede ayudar con muchísimas cosas: resolver problemas complejos, generar código o brindar asesoramiento en materia de seguridad.
Imagina que has subido código para buscar problemas de seguridad. ¿Y si incluyera una contraseña? Las reglas deberían limitar el modelo LLM para evitar que se filtre la contraseña. ¿Es posible extraer este secreto a pesar de ello?

Intenta encontrarlo a través del primer ejercicio de este juego de preguntas en https://gandalf.lakera.ai/[este juego].


Tenga en cuenta que https://gandalf.lakera.ai/[el juego de preguntas] es completamente gratuito y de código abierto. Esto significa que podría estar fuera de línea y tardar unos minutos en volver a funcionar después de su primera solicitud. Por favor, no realice pruebas de fuzzing ni pruebas dinámicas en el sitio web (por ejemplo, no use ZAP ni Burp). ¡Asegúrese de que otros también puedan jugar!

Tenga en cuenta que solíamos usar https://gpa.43z.one/[otro juego de preguntas], que se cerró debido a su costo, por lo que es posible que LLM/AI no esté aquí para quedarse para siempre ;-).
