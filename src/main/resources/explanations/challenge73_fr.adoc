=== Défi 73 : Trouvez le secret dans les fichiers d’instructions des agents

Les agents de codage IA chargent les fichiers d'instructions et de contexte depuis le référentiel à chaque
session : `AGENTS.md`, `CLAUDE.md`, `.cursor/rules/*.mdc`, `.windsurfrules` et
autres formats similaires. Comme ces fichiers ne sont que de la « documentation », ils reçoivent rarement le même
traitement que le code source, mais un modèle les lit, ils sont copiés sur la machine de chaque
développeur et versionnés dans le contrôle de version.

Ce dépôt inclut de tels fichiers d'instructions dans son conteneur de développement. Ils se trouvent
dans le dossier link:https://github.com/OWASP/wrongsecrets/tree/master/.devcontainer[`.devcontainer`]
avec le contenu suivant :

- `.devcontainer/AGENTS.md`
- `.devcontainer/CLAUDE.md`
- `.devcontainer/.cursor/rules/project.mdc`
- `.devcontainer/.windsurfrules`

L'un d'eux intègre un identifiant partagé afin que chaque agent réutilise le même
valeur « par commodité ». Lisez les fichiers et soumettez le jeton de déploiement de staging exposé.

[NOTE]
====
Rien n'est codé ni crypté ici : voici à quoi ressemble un fichier de contexte d'agent
fuité en conditions réelles.
====
