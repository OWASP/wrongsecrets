Puedes resolver este desafío siguiendo estos pasos:

1. Asegúrese de que Container Insights esté habilitado para su clúster AKS, de modo que la salida del contenedor llegue a su espacio de trabajo https://portal.azure.com[*Log Analytics*].
2. Consulta la tabla `ContainerLogV2` para el evento de auditoría, ya sea en el portal o desde la CLI:
+
[source,shell]
----
az monitor log-analytics query \
  --workspace <workspaceId> \
  --analytics-query "ContainerLogV2 | where LogMessage contains 'encoded credential' | project TimeGenerated, LogMessage | take 5"
----
o utilice:
[source, shell]
----
ContainerLogV2
| where LogMessage contains "encoded credential"
| project TimeGenerated, LogMessage
| take 5
----
3. En espacios de trabajo más antiguos, la tabla se llama `ContainerLog` y la columna `LogEntry`, así que utilice `ContainerLog | where LogEntry contains 'encoded credential'` en su lugar.
4. Toma el blob Base64 del mensaje y decodifícalo: `echo '<blob>' | base64 -d`. Ese valor decodificado es la respuesta.

¿Aún no ves nada? El evento se emite la primera vez que se abre el desafío, así que accede a la página una vez y vuelve a intentarlo.
