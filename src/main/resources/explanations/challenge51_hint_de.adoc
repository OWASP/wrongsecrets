Diese Herausforderung kann auf folgende Weise gelöst werden:

- Verwende die docker-compose-Datei (`challenge51docker-compose.yml`), um die Container zu erstellen und das Geheimnis zu finden.
  1. Klone das Repository, das die Challenge-Dateien enthält.
  2. Suche die Datei `challenge51docker-compose.yml` im Repository und navigiere zu diesem Speicherort.
  3. Anmeldeinformationen identifizieren:
    Überprüfe im Abschnitt „environments“ der Datei challenge51docker-compose.yml auf Variablen wie:
     * `db_user`
     * `db_password`
     * `db_name`
  4. Jetzt kannst du die Docker Compose-Befehle ausführen, um deinen Dienst zu erstellen und auszuführen:
     * `export DOCKER_BUILDKIT=1`
     * `docker compose -f challenge51docker-compose.yml build`
     * `docker compose -f challenge51docker-compose.yml run myservice`
  5. Die Antwort befindet sich in der Ausgabe.

- Die Geheimnisse direkt im Dateisystem finden:
   1. Klone das Repository, das die Challenge-Dateien enthält.
   2. Verwende die Dateiverweise in `challenge51docker-compose.yml`, um die Dateien zu finden, die die Geheimnisse enthalten.
   3. Öffne die Datei, um das Geheimnis zu finden.
