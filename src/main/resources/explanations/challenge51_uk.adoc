=== Виклик «Розкриті секрети Docker»

У цьому випробуванні ви дослідите важливість безпечного керування конфіденційною інформацією за допомогою секретів Docker у файлі [файл Docker Compose] https://raw.githubusercontent.com/OWASP/wrongsecrets/refs/heads/master/src/main/resources/challenges/challenge-51/challenge51docker-compose.yml]. Секрети Docker призначені для безпечного передавання та зберігання конфіденційних даних, таких як паролі, ключі API та сертифікати, у сервісах Docker. Однак неправильне поводження або неправильні налаштування можуть ненавмисно розкрити ці секрети, що призведе до потенційних ризиків для безпеки.

*Acme Inc.*, швидкозростаюча платформа електронної комерції, нещодавно зіткнулася з підозрілою активністю, яка свідчить про те, що конфіденційні дані клієнтів могли бути скомпрометовані. Внутрішній аудит показав, що розробник ненавмисно розкрив облікові дані бази даних, зберігаючи секретні файли в репозиторії та надсилаючи їх до публічного репозиторію Git. Крім того, програма неефективно використовувала секрети Docker, що призводило до розкриття конфіденційної інформації у відкритому тексті в запущених контейнерах.

Вас найняли консультантом з технічної безпеки, ваше завдання — захистити розкриті секрети для захисту конфіденційної інформації? Наразі визначте неправильні конфігурації та повідомте пароль бази даних у полі нижче, щоб показати проблему.
