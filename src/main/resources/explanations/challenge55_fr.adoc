=== .ssh Bastion ?

Nous avons vu de nombreux conteneurs dits « bastions ». Il s'agit de créer un conteneur Docker et d'y intégrer le « secret » d'authentification auprès de l'hôte. Ce secret est souvent une paire de clés SSH utilisée pour l'authentification. Dans certains cas, la paire de clés est enregistrée dans Git, et dans d'autres, elle est injectée dans le conteneur avant son déploiement sur un registre.

Pour que le conteneur bastion fonctionne, nous devons intégrer un fichier de configuration SSH (`.ssh/config`) afin de simplifier la configuration de la connexion SSH en stockant les configurations spécifiques à l'hôte.
