=== Підказка до завдання 62

Цей виклик демонструє, як сервер MCP із надмірно привілейованим обліковим записом служби Google дозволяє ескалацію привілеїв.

**Де шукати:**

1. **Сервер MCP працює за адресою `/mcp62`** на головному порту програми
2. **Сервер MCP надає інструмент `read_google_drive_document`**, який використовує обліковий запис служби Google для читання документа
3. **Вам не потрібні дійсні облікові дані Google** — обліковий запис служби вже налаштовано в додатку

**Покроковий підхід:**

Спочатку перелічіть інструменти, які пропонує сервер MCP:

[source,bash]
----
curl -s -X POST http://localhost:8080/mcp62 \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
----

Потім викличте `read_google_drive_document`, щоб прочитати документ:

[source,bash]
----
curl -s -X POST http://localhost:8080/mcp62 \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"read_google_drive_document","arguments":{}}}'
----

**На що звернути увагу:**

- Відповідь містить вміст документа Google Диска
- Документ містить секретну відповідь на це завдання
- Валідатор відповідей використовує значення між `<secret>` та `</secret>` з цього вмісту
- Зверніть увагу, що ви отримали доступ до документа, до читання якого у вас немає прямих прав — обліковий запис служби сервера MCP надав цей доступ.

**Примітка керуючого:** Контролер MCP зберігає обмежений кеш документів, щоб зменшити кількість повторних викликів API Диска.

**Пам’ятайте:** Це приклад ескалації привілеїв через MCP-сервер. Обліковий запис служби має більше дозволів, ніж ви (абонент), а MCP-сервер не застосовує елементи керування доступом на рівні абонента.
