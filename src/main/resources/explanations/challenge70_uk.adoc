=== Завдання 70: Знайдіть секрет у наборі навичок Клода

Навички Claude розповсюджуються як експортовані пакети `.skill`: zip-архів, що містить папку з файлом `SKILL.md`, який описує, коли використовувати навичку, а також будь-які скрипти та довідкові матеріали, необхідні для цієї навички. Весь пакет розпаковується на комп'ютері, на якому його встановлено.

Це робить пакет навичок чудовим сховищем, оскільки рецензенти зазвичай читають `SKILL.md` і на цьому зупиняються. Цікава частина зазвичай знаходиться у файлах поруч із ним.

Ця програма постачає навичку Клода під назвою `incident-reporter`. Експортований пакет навичок знаходиться в папці ресурсів і доступний для завантаження за посиланням:link:/skills/claude/incident-reporter.zip[`/skills/claude/incident-reporter.zip`].

Завантажте пакет, розпакуйте його та визначте токен, за допомогою якого завантажувач проходить автентифікацію.

Джерело навичок також доступне на GitHub за посиланням: link:https://github.com/OWASP/wrongsecrets/blob/master/src/main/resources/challenges/challenge-70/claude-skill/incident-reporter.skill[`src/main/resources/challenges/challenge-70/claude-skill/incident-reporter.skill`].

[NOTE]
====
Файл `SKILL.md` чистий. Читання лише початкової точки навички не є переглядом.
====
