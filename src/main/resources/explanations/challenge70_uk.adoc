=== Завдання 70: Знайдіть секрет у бандлі скілів Claude

Скіли Claude поширюються у вигляді експортованих бандлів `.skill`: zip-архів із текою, що містить `SKILL.md` із описом того, коли використовувати скіл, а також усі скрипти та довідкові матеріали, потрібні скілу. Уесь бандл розпаковується на машині, де його встановлюють.

Це робить бандл скілу чудовим місцем для ховання, бо рев'юери зазвичай читають `SKILL.md` і на цьому зупиняються. Цікава частина зазвичай міститься у сусідніх файлах.

Цей застосунок містить Claude-скіл на ім'я `incident-reporter`. Експортований бандл скілу знаходиться в теці ресурсів і доступний для завантаження за посиланням link:/skills/claude/incident-reporter.zip[`/skills/claude/incident-reporter.zip`].

Завантажте бандл, розпакуйте його і з'ясуйте, який токен використовує для автентифікації той, хто його завантажує.

Вихідний код скілу також доступний на GitHub: link:https://github.com/OWASP/wrongsecrets/blob/master/src/main/resources/challenges/challenge-70/claude-skill/incident-reporter.skill[`src/main/resources/challenges/challenge-70/claude-skill/incident-reporter.skill`].

[NOTE]
====
`SKILL.md` чистий. Читати лише точку входу скілу — це ще не рев'ю.
====
