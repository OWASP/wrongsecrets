Puedes resolver este desafío mediante las siguientes soluciones alternativas:

1. Analice el archivo terraform.tfstate con Trufflehog:
- Después de haber creado la infraestructura siguiendo las instrucciones del archivo README de la carpeta `azure`, permanezca en esa carpeta y ejecute `trufflehog3 --output=terraform-infra.json --format=json .`
- Ahora, abre el archivo terraform-infra.json y empieza a buscar la contraseña.

2. Encuentra el secreto en Key Vault (esta es la forma fácil, prueba las otras :) ):
- Inicie sesión en Azure https://portal.azure.com[cloud] con la cuenta con la que creó la configuración de WrongSecrets.
- Navegar a la bóveda de llaves
- Obtener los datos de wrongsecret

3. Encuentra el secreto accediendo al POD mediante exec-in.
- Asegúrese de tener Kubectl instalado como se define en el archivo README.MD y asegúrese de que kubectl esté configurado para enviar comandos al clúster correcto.
- Ahora ejecuta `kubectl get pods`. Aquí verás todos los Pods activos en el espacio de nombres en el que te encuentras, que para esta aplicación normalmente es `default` (a menos que tu administrador/tutor especifique lo contrario).
- Ahora, para tu instancia del pod WrongSecrets, ejecuta `kubectl exec -it secret-challenge-<rest of the name of the pod from the prev.step> -- sh`.
- Examine los datos que puede encontrar en `/mnt/secrets-store`.
