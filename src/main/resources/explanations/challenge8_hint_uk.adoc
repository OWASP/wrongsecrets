Ви можете вирішити цю проблему, виконавши такі кроки:

1. Отримайте секрет із журналу
 - Ви використовуєте контейнер Docker? Використовуйте `docker logs <containerID>`, щоб отримати логи та знайти значення для challenge8.
 - Ви використовуєте K8s? Знайдіть под (`kubectl get pods | grep secret`), а потім виконайте `kubectl logs -f <nameOfThePod>`, щоб отримати логи та знайти значення для завдання 8.
