Vous pouvez relever ce défi grâce aux solutions alternatives suivantes :

1. Vérifiez l'état du secret dans Git :
- Pouvez-vous voir où, dans Git, nous avons stocké le fichier `secrets-secret.yml` ? Sinon, effectuez une recherche.
- Examinez le champ `Data` : que pouvez-vous y trouver ? Veuillez noter que les secrets sont encodés en base64. Une fois intégrés aux charges de travail, ils sont décodés.

2. Demandez poliment en utilisant Kubectl :
- Assurez-vous d'avoir installé Kubectl comme indiqué dans le fichier README.MD et que kubectl est configuré pour envoyer des commandes au bon cluster.
- Maintenant, exécutez `kubectl get secrets`. Vous verrez ici toutes les configmaps actives dans l'espace de noms dans lequel vous vous trouvez, qui est normalement `default` pour cette application (sauf indication contraire de votre administrateur/formateur).
- Exécutez maintenant `kubectl get secret funnystuff -o Yaml`. Pouvez-vous voir le secret ? Quelle est sa valeur une fois décodée en base64 ?

3. Accédez au pod et récupérez les données :
- Assurez-vous d'avoir installé Kubectl comme indiqué dans le fichier README.MD et que kubectl est configuré pour envoyer des commandes au bon cluster.
- Maintenant, exécutez `kubectl get pods`. Vous verrez alors tous les pods actifs dans l'espace de noms actuel, qui est normalement `default` pour cette application (sauf indication contraire de votre administrateur/formateur).
- Maintenant, pour votre instance du pod WrongSecrets, exécutez `kubectl exec -it secret-challenge-<rest of the name of the pod from the prev.step> -- sh`.
- Exécutez maintenant `env | grep SPECIAL_SPECIAL_K8S_SECRET` pour afficher votre secret. Notez qu'aucun décodage n'est nécessaire, car le secret est désormais monté.


Au fait : la commande `kubectl get <resourcetype> -A` vous donne un aperçu de toutes les instances de ce type de ressource dans tous les espaces de noms auxquels vous avez accès. Cela montre combien il est important de ne pas donner accès à tous les espaces de noms de votre cluster, car cela pourrait entraîner la divulgation d'éléments de configuration importants.
