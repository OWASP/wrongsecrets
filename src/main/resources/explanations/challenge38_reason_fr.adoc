*Pourquoi faut-il faire attention aux notes Git ?*

1. Comme pour tous les dépôts Git, une fois qu'un secret est divulgué ici, il est très difficile, voire impossible, de le supprimer de tout l'historique.

2. Git Notes semble être une fonctionnalité rarement utilisée de Git ; par conséquent, de nombreux scanners de secrets ne les vérifient pas. Cela signifie qu'elle peut passer inaperçue lors de l'intégration continue.*

**Le problème n° 2 fait actuellement l'objet d'une étude par l'équipe de WrongSecrets. Nous analysons un échantillon des plus grands projets open source afin de déterminer si les notes Git y sont utilisées. Si tel est le cas, nous envisagerons de contribuer aux scanners de secrets pour les prendre en charge. Dans le cas contraire, nous pourrions recommander de simplement ne pas utiliser cette fonctionnalité de Git afin d'éviter tout problème. Suivez l'avancement de ce projet sur le Slack de WrongSecrets.**

Que faire à la place :
- Ne stockez pas de secret dans les notes Git. Intégrez les notes Git aux processus d'analyse de secrets et de revue du dépôt plutôt que de supposer que les scanners les examinent.
- Si un secret a été validé dans une note, révoquez-le ou régénérez-le et considérez-le comme exposé, même si la note est supprimée par la suite.
