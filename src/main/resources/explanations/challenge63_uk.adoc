=== Завдання із зашитим ключем шифрування
Це завдання демонструє поширену, але небезпечну помилку: шифрування секрету, тоді як ключ шифрування зашито в тому самому вихідному файлі.

Розробник спробував захистити секрет, зашифрувавши його за допомогою AES. Проте і ключ шифрування, і вектор ініціалізації (IV) безпосередньо зашиті у вихідний код Java поруч із шифротекстом. Через це шифрування є повністю неефективним — будь-хто, хто має доступ до вихідного коду, може легко розшифрувати секрет.

**Твоя мета:**
1. **Знайди вихідний файл Java** для цього завдання в кодовій базі
2. **Знайди зашитий ключ AES та IV** у вихідному коді
3. **Розшифруй шифротекст** за допомогою знайденого ключа та IV
4. **Надішли відкритий текст** як свою відповідь

**Як розшифрувати:**
[source,bash]
----
echo "TDPwOvcLsbCWV5erlk6OHFnlFoXNtdQOt2JQeq+i4Ho=" | openssl enc -d -aes-128-cbc \
  -K $(echo -n "SuperSecretKey12" | xxd -p) \
  -iv $(echo -n "InitVector123456" | xxd -p) \
  -base64
----
