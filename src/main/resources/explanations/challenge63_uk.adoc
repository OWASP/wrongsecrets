=== Виклик жорстко закодованого ключа шифрування
Ця проблема демонструє поширену, але небезпечну помилку: шифрування секрету під час жорсткого кодування ключа шифрування в тому ж вихідному файлі.

Розробник спробував захистити секрет, зашифрувавши його за допомогою AES. Однак і ключ шифрування, і вектор ініціалізації (IV) жорстко закодовані безпосередньо у вихідному коді Java разом із зашифрованим текстом. Це робить шифрування абсолютно неефективним — будь-хто, хто має доступ до вихідного коду, може тривіально розшифрувати секрет.

**Ваша мета:**
1. **Знайдіть вихідний файл Java** для цього завдання в кодовій базі
2. **Знайдіть жорстко закодований ключ AES та IV** у вихідному коді
3. **Розшифруйте зашифрований текст**, використовуючи знайдений ключ та IV.
4. **Надішліть відкритий текст** як свою відповідь

**Як розшифрувати:**
[source,bash]
----
echo "TDPwOvcLsbCWV5erlk6OHFnlFoXNtdQOt2JQeq+i4Ho=" | openssl enc -d -aes-128-cbc \
  -K $(echo -n "SuperSecretKey12" | xxd -p) \
  -iv $(echo -n "InitVector123456" | xxd -p) \
  -base64
----
