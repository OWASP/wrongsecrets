=== Secret basé sur une ConfigMap Kubernetes

Intégrer une configuration en dur dans Docker n'était pas judicieux. Mais qu'en est-il d'une ConfigMap dans l'espace de noms par défaut sans RBAC ?

Si ce défi est activé, vous exécutez cette commande depuis un cluster Kubernetes. Pouvez-vous utiliser `kubectl` pour trouver le secret ? Ou bien, avez-vous essayé de consulter le dépôt où le cluster est configuré ? Vous l'auriez peut-être repéré si la ConfigMap avait été enregistrée sur Git.
