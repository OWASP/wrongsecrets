=== Challenge 77: Секрет GitHub Actions, який можна форкнути

Секрети GitHub Actions не копіюються, коли хтось створює форк репозиторію. Тому workflow, що
залежить від `${{ secrets.SOMETHING }}`, перестає працювати в кожному форку. Спокусливе
"виправлення" — взагалі відмовитися від секрету GitHub: зашифрувати значення, закомітити шифротекст
у workflow і розшифровувати його під час запуску. Тепер workflow працює в кожному форку.

Проблема в тому, що workflow також потребує ключа розшифрування, і цей ключ опинився в
тому самому файлі. Кожен, хто форкає або навіть просто читає цей репозиторій, отримує
зашифрований секрет разом з усім необхідним для його розшифрування.

Перегляньте workflow
link:https://github.com/OWASP/wrongsecrets/blob/master/.github/workflows/challenge77.yml[`.github/workflows/challenge77.yml`],
відновіть секрет і надішліть його значення у відкритому вигляді.

[NOTE]
====
Ви можете розв'язати це завдання офлайн за допомогою `openssl` або створивши форк репозиторію,
увімкнувши GitHub Actions у своєму форку та запустивши workflow там.
====
