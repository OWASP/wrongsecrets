Diese Herausforderung lässt sich durch folgende alternative Lösungsansätze bewältigen:

1. Durchsuchen Sie terraform.tfstate mit Trufflehog:
- Nachdem Sie die Infrastruktur gemäß den Anweisungen in der README-Datei des Ordners `gcp` erstellt haben, bleiben Sie in diesem Ordner und führen Sie `trufflehog3 --output=terraform-infra.json --format=json .` aus.
- Öffnen Sie nun die Datei terraform-infra.json und suchen Sie nach dem Passwort.

2. Finde das Geheimnis im Google Secrets Manager (dies ist der einfache Ausweg, probiere aber auch die anderen aus :) ):
- Melden Sie sich bei Google unter https://cloud.google.com/[cloud] mit dem Konto an, mit dem Sie das WrongSecrets-Setup erstellt haben.
- Holen Sie sich die Daten von wrongsecrets1

3. Finde das Geheimnis, indem du dich in den POD einloggst.
- Stellen Sie sicher, dass Kubectl wie in der README.MD beschrieben installiert ist und dass kubectl so konfiguriert ist, dass Befehle an den richtigen Cluster gesendet werden.
- Führen Sie nun `kubectl get pods` aus. Hier sehen Sie alle aktiven Pods im aktuellen Namespace, der für diese Anwendung normalerweise `default` ist (sofern nicht anders von Ihrem Administrator/Trainer angegeben).
- Führen Sie nun für Ihre Instanz des WrongSecrets-Pods den Befehl `kubectl exec -it secret-challenge-<rest of the name of the pod from the prev.step> -- sh` aus.
- Untersuchen Sie die Daten, die Sie in `/mnt/secrets-store` finden.
