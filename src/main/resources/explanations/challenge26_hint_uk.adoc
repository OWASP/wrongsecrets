Ви можете знайти попередній стан одним із двох альтернативних рішень:

1. Знайдіть попередній блок, надіславши запит до https://infura.io/[Infura]:
- Знайдіть номер блоку для будь-якого блоку після створення контракту та до його оновлення.
- Створіть ключ Infura за адресою https://infura.io/[Infura].
- Пошук стану зберігання контракту для цього блоку. Наведена нижче команда є прикладом порівняно з API infura:

    curl https://goerli.infura.io/v3/${ваш-інфура-ключ}
    -X ПОСТ \
    -H "Тип вмісту: application/json" \
    -d '{"jsonrpc":"2.0", "метод": "eth_getStorageAt", "params": ["${адреса контракту}", "0x0", "${номер блоку}"], "id": 1}'

2. Перегляньте створення контракту на https://etherscan.io/[Etherscan]:
- Перегляньте транзакцію створення контракту на EtherScan
- Зверніться до штату та перевірте сховище
