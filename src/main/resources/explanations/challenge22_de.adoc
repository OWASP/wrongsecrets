=== Verstecken in Binärdateien Teil 4: Die Rust-Binärdatei

Ähnlich wie beim Verstecken von Geheimnissen in einer in C geschriebenen Anwendung ist dies auch in Rust möglich. Ghidra ist jedoch standardmäßig nicht besonders gut für die Analyse von Rust geeignet. Können Sie das Geheimnis in unserer Binärdatei finden?

Lasst uns den Mythos widerlegen, dass „Geheimnisse in nativ kompilierten Anwendungen schwer zu finden sind“ für Rust: Könnt ihr das Geheimnis in https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-rust[wrongsecrets-rust] (oder https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-rust-arm[wrongsecrets-rust-arm], https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-rust-linux[wrongsecrets-rust-linux]) finden?

Versuchen Sie, die Binärdatei herunterzuladen und lokal auszuführen (z. B. `./wrongsecrets-rust<theversion you need> <your answer>`).
