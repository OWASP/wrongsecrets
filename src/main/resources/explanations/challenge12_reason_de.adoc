*Warum es eine schlechte Idee ist, Geheimnisse in Containern zu speichern*

Wie du inzwischen feststellen konntest, lassen sich alle in einem Container gespeicherten Geheimnisse leicht aufspüren. Ob es sich um eine Umgebungsvariable, eine Datei oder eine andere Eigenschaft handelt: Wenn ein System sie lesen kann, kann es auch ein Mensch.

Da es als bewährte Methode gilt, einen Container unveränderlich und versioniert zu halten, bleibt das Geheimnis oft für immer im Container erhalten, es sei denn, man entfernt es erneut aus der Registry.

Hinweis: Wenn du die Anzahl der ausführbaren Dateien in einem Container reduzierst (sodass keine Shell mehr möglich ist), vergiss nicht den `Openssl client` und einfache Binärdateien wie `ls` und `cat`, die gegebenenfalls ebenfalls entfernt werden müssen. Dies hilft, zu verhindern, dass ein Angreifer den Inhalt deines Containers durchsucht.

Halte Geheimnisse aus Image-Layern und stelle sie zur Laufzeit über einen Secrets Manager oder einen plattformeigenen Mechanismus bereit, wobei der Zugriff auf die Workload beschränkt bleibt, die ihn benötigt. Rotiere jedes Geheimnis, das in einem Image enthalten war.
