=== Un autre secret client

Le client reçoit une valeur aléatoire du serveur et doit la renvoyer comme réponse pour prouver son identité. C'est souvent le cas, par exemple, lorsqu'il faut fournir un jeton de session. Ce jeton est généré aléatoirement au démarrage du serveur ; il est donc impossible de le trouver dans le code. Mais que se passe-t-il si nous le stockons de manière non sécurisée côté client ?
