=== Herausforderung: Aufgedeckte Docker-Geheimnisse

In dieser Challenge lernen Sie, wie wichtig die sichere Verwaltung sensibler Informationen mithilfe von Docker Secrets in einer Docker Compose-Datei (https://raw.githubusercontent.com/OWASP/wrongsecrets/refs/heads/master/src/main/resources/challenges/challenge-51/challenge51docker-compose.yml) ist. Docker Secrets dienen der sicheren Übertragung und Speicherung sensibler Daten wie Passwörter, API-Schlüssel und Zertifikate innerhalb von Docker-Diensten. Unsachgemäße Handhabung oder Fehlkonfigurationen können diese Secrets jedoch unbeabsichtigt offenlegen und somit potenzielle Sicherheitsrisiken bergen.

*Acme Inc.*, eine schnell wachsende E-Commerce-Plattform, sah sich kürzlich verdächtigen Aktivitäten ausgesetzt, die auf eine mögliche Gefährdung sensibler Kundendaten hindeuten. Eine interne Prüfung ergab, dass ein Entwickler versehentlich Datenbankzugangsdaten offengelegt hatte, indem er geheime Dateien in einem Repository speicherte und diese in ein öffentliches Git-Repository hochlud. Darüber hinaus nutzte die Anwendung Docker Secrets nicht effektiv, was zur Offenlegung sensibler Informationen im Klartext innerhalb laufender Container führte.

Sie wurden als Berater für technische Sicherheit eingestellt. Ihre Aufgabe ist es, die offengelegten Geheimnisse zu sichern und sensible Informationen zu schützen. Identifizieren Sie zunächst die Fehlkonfigurationen und geben Sie das Datenbankpasswort im untenstehenden Feld an, um das Problem zu verdeutlichen.
