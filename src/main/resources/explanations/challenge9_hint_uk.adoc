Ви можете вирішити цю проблему за допомогою таких альтернативних рішень:

1. Перекопайте terraform.tfstate за допомогою Trufflehog:
- Після того, як ви зібрали інфраструктуру, дотримуючись інструкцій у файлі README папки `aws`, залишайтеся в цій папці та запустіть `trufflehog3 --output=terraform-infra.json --format=json .`
- Тепер відкрийте файл terraform-infra.json та почніть шукати пароль.

2. Знайдіть секрет у AWS Secrets Manager (це найпростіший спосіб, спробуйте інші :) )
- увійдіть до AWS https://console.aws.com/[Console], використовуючи обліковий запис, за допомогою якого ви створили налаштування WrongSecrets.
- перейдіть до менеджера секретів AWS
- отримати дані з wrongsecrets1

3. Знайдіть секрет, виконавши команду в POD
- Переконайтеся, що у вас встановлено Kubectl, як визначено у файлі README.MD, і що kubectl налаштовано на надсилання команд до правильного кластера.
- тепер виконайте команду `kubectl get pods`. Тут ви побачите всі поди, активні в просторі імен, у якому ви знаходитесь, який для цієї програми зазвичай є `default` (якщо інше не вказано вашим адміністратором/тренером).
- тепер для вашого екземпляра пода WrongSecrets виконайте `kubectl exec -it secret-challenge-<rest of the name of the pod from the prev.step> -- sh`.
- тепер перевірте дані, які ви можете знайти в `/mnt/secrets-store`
