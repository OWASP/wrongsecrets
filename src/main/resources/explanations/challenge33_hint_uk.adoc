Цю проблему можна вирішити, переглянувши метадані секрету:

1. розглядаючи це через код
- знайти секретне визначення в git (Challenge33.yml)
- знайти секретне значення в метаданих.
2. дивлячись на це через отримання секрету
- підключитися до кластера k8s за допомогою kubectl
- викликати `kubectl get secret challenge33 -o yaml`, щоб отримати всі необхідні дані.
- Знайдіть секретне значення в метаданих.
3. неправильне використання налагодження під час перерахування всіх секретів
- підключитися до кластера k8s за допомогою kubectl
- викликати `kubectl get secrets -v9` для отримання всіх необхідних даних
- Знайдіть секретне значення в метаданих.
