Het geheim is verborgen in het bestand `.gitignore` als een AES-256-CBC-versleuteling.

Volg deze stappen om het geheim te ontsleutelen:

1. Zoek het versleutelde commentaar en de sleutel om het te ontsleutelen in `.gitignore`.
2. Gebruik OpenSSL om te ontsleutelen:
+
[source,bash]
----
 echo "h0vRDUS3VDN2gwfd1oftcMtD/YlKE0YfHLTvyk/lrY4=" | openssl enc -aes-256-cbc -K 6b3b913c09d62238b9b8c0cc78904e7e1f9a99fd0a04ebae50a8a9881d452bbd \
  -iv 30313233343536373839616263646566 \
  -nosalt -base64 -d
----
