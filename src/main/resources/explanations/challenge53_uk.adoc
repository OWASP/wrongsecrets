=== Витік контейнера налагодження

Сучасні хмарні середовища часто покладаються на інструменти налагодження для усунення проблем у запущених програмах. Однак, коли можливості налагодження залишаються відкритими у робочому середовищі, вони можуть розкрити конфіденційну інформацію.

Розгортання Kubernetes було неправильно налаштовано [challenge53](https://github.com/OWASP/wrongsecrets/blob/master/k8s/challenge53/secret-challenge53.yml), що дозволило розробникам приєднати контейнер налагодження до запущеної програми. Усередині цього поду бінарний файл містить секрет у пам'яті. Зазвичай цей секрет був би захищений, але завдяки доступу для налагодження його можна отримати.
