Laden Sie das exportierte Skill-Bundle herunter und entpacken Sie es:

----
curl -sO http://localhost:8080/skills/claude/incident-reporter.zip
unzip incident-reporter.zip
----

Die Datei `SKILL.md` verweist lediglich auf den mitgelieferten Uploader. Öffnen Sie `incident-reporter/scripts/upload_report.py` und sehen Sie sich `UPLOAD_TOKEN_B64` an.

Dieser Wert ist noch nicht die Antwort: Der Autor hat ihn Base64-kodiert, um eine Fehlermeldung des Geheimnisscanners zu vermeiden. Dekodieren Sie ihn beispielsweise mit `base64 -d` und übermitteln Sie das dekodierte Token.
