1. Für den ersten Hash (MD5):
- Verwende ein Tool wie Hashcat:
- Installiere https://hashcat.net/hashcat/[Hashcat]
- Lade die Datei https://github.com/brannondorsey/naive-hashcat/releases/download/data/rockyou.txt[rockyou.txt password list] herunter.
- Führe Hashcat auf dem Hash aus: `hashcat -m 0 "2ab96390c7dbe3439de74d0c9b0b1767" /path/to/file/rockyou.txt`

2. Für den zweiten Hash (SHA1):
