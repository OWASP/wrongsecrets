=== Нотатки Git

Повідомлення про коміти Git можуть бути постійною проблемою.

Можна використовувати коротке повідомлення, незрозумілу плутанину або просте натискання клавіш у git-повідомленні, поки вам не доведеться невдало переглянути його. На цьому етапі ці неохайні повідомлення можуть перетворитися на кошмар.

Нотатки Git допоможуть вирішити цю проблему. Ця тема існує вже давно, але часто її не помічають. Додайте додаткові метадані про коміт, не впливаючи на саме повідомлення коміту.

Як і в будь-якому Git, після того, як інформація закомічена, дуже важко видалити всі посилання на неї. Що може піти не так?
