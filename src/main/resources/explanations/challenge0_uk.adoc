=== Відкриття змагання

Ласкаво просимо до вступного випробування OWASP WrongSecrets!

У цьому челенджі ми пояснимо вам усе, що потрібно знати, щоб грати в OWASP WrongSecrets.

Кожен виклик полягає у пошуку секрету, який не був добре прихований та/або налаштований всередині нашого https://github.com/OWASP/wrongsecrets[код програми], https://hub.docker.com/r/jeroenwillemsen/wrongsecrets[контейнер Docker] або в одній із пов'язаних частин https://github.com/OWASP/wrongsecrets#table-of-contents[системи].

Щойно ви знайдете секретний код, ви можете ввести його в поле нижче та натиснути «Надіслати». Кнопка «Очистити» очистить поле введення.
Хочете зіграти в челендж ще раз? Натисніть кнопку «Скинути».

Правильна відповідь нижче — `The first answer`. Скопіюйте її в поле та натисніть «Надіслати».

Отримайте масу задоволення від складніших завдань ;-).

Примітка: деякі з майбутніх завдань вимагатимуть використання додаткових інструментів для пошуку рішення. Для цього вам знадобиться комп’ютер з усіма встановленими інструментами. Не хочете встановлювати їх самостійно? Ви можете скористатися контейнером, щоб мати їх усі доступними одночасно, за допомогою

[source, shell]
docker run -p 3000:3000 -v /var/run/docker.sock:/var/run/docker.sock jeroenwillemsen/wrongsecrets-desktop:latest


Потім у вашому браузері перейдіть за адресою http://localhost:3000[http://localhost:3000], щоб знайти веб-сторінку з усіма необхідними інструментами, яка чекає на вас.
