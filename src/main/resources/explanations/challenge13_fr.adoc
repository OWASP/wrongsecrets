=== Actions pouvant être dupliquées sur Github

Lorsque vous souhaitez gérer des secrets dans votre pipeline CI/CD, vous devez toujours vous demander : qui peut y avoir accès ?
Parviendrez-vous à trouver le secret en utilisant l'action Github ?

Remarque : ce défi est en même temps un défi de « mauvaise crypto », mais un peu moins facile de ce fait.
