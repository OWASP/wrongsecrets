*Чому виконувані JAR-файли та Android APK-файли не слід використовувати для приховування секретів.*

Запущені JAR-файли не є безпечним місцем для приховування секретів. Як і Android APK, вони є архівами, які надсилають байт-код та ресурси безпосередньо зловмиснику, що спрощує перевірку вбудованих рядків, констант та допоміжних методів за допомогою звичайних інструментів зворотного проектування.

Якщо артефакт Java на стороні клієнта потребує секрету для роботи, припускайте, що цей секрет можна отримати після завантаження файлу. Зберігайте справжні секрети на надійному сервері та розголошуйте їх лише після належної автентифікації та авторизації.

Якщо ви хочете отримати більше практики зворотного проектування Java та Android, ознайомтеся з https://github.com/OWASP/MASTG-Hacking-Playground[OWASP MASTG Hacking Playground].
