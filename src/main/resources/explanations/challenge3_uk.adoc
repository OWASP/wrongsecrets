=== Пароль на основі Docker ENV

Чи знаєте ви, що ви також можете використовувати ENV у контейнерах Docker для встановлення пароля? Яка чудова ідея — поділитися цим з усіма!

Ви можете легко виявити секрет, подивившись на те, як були побудовані шари, або виявивши його за допомогою інструменту, такого як https://github.com/goodwithtech/dockle[*Dockle*].
