=== Desafío de secretos de Docker al descubierto

En este desafío, explorarás la importancia de gestionar de forma segura la información confidencial mediante secretos de Docker en un archivo Docker Compose (https://raw.githubusercontent.com/OWASP/wrongsecrets/refs/heads/master/src/main/resources/challenges/challenge-51/challenge51docker-compose.yml). Los secretos de Docker están diseñados para transmitir y almacenar de forma segura datos confidenciales como contraseñas, claves API y certificados dentro de los servicios de Docker. Sin embargo, un manejo inadecuado o una configuración incorrecta pueden exponer estos secretos de forma inadvertida, lo que conlleva posibles riesgos de seguridad.

Acme Inc., una plataforma de comercio electrónico de rápido crecimiento, ha detectado recientemente actividades sospechosas que sugieren una posible filtración de datos confidenciales de sus clientes . Una auditoría interna revela que un desarrollador expuso inadvertidamente las credenciales de la base de datos al almacenar archivos secretos en un repositorio y subirlos a un repositorio Git público. Además, la aplicación no utilizaba correctamente los secretos de Docker, lo que provocó la exposición de información confidencial en texto plano dentro de los contenedores en ejecución.

Te han contratado como Consultor de Seguridad Técnica. Tu trabajo consiste en proteger los secretos expuestos para salvaguardar la información confidencial. Por ahora, identifica las configuraciones incorrectas e informa la contraseña de la base de datos en el cuadro a continuación para mostrar el problema.
