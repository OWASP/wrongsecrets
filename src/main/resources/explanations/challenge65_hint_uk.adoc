У цьому завданні використовується звичайний JAR-файл Java CLI.

Ви можете вирішити це таким чином:

1. Знайдіть скомпільований клас, який містить секрет:
- Завантажити `wrongsecrets-java.jar`.
- Запустіть `jar tf wrongsecrets-java.jar` та знайдіть `io/github/owasp/wrongsecrets/WrongSecretsPlain.class`.
- Відкрийте цей клас у CFR, JADX, IntelliJ IDEA або іншому декомпіляторі.

2. Перевірте, як зберігається секрет:
- Виконайте команду `javap -c -p -classpath wrongsecrets-java.jar io.github.owasp.wrongsecrets.WrongSecretsPlain`.
- Знайдіть метод `getSecret()` та перегляньте інструкцію `ldc`, яку він використовує.
- Зверніть увагу, що секрет зберігається як звичайна рядкова константа, а не обфускується.

3. Відновіть значення та надішліть його:
- Скопіюйте рядок, повернутий `getSecret()`, з виводу декомпілятора або байт-коду.
- Якщо вам потрібна ще одна швидка перевірка, такі інструменти, як `strings wrongsecrets-java.jar`, також можуть допомогти виявити читабельні константи.
- Надішліть відновлений рядок як відповідь.
