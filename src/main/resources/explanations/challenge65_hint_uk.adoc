Це завдання використовує простий JAR-файл Java CLI.

Ти можеш розв'язати його так:

1. Знайти скомпільований клас, який містить секрет:
- Завантаж `wrongsecrets-java.jar`.
- Виконай `jar tf wrongsecrets-java.jar` і знайди `io/github/owasp/wrongsecrets/WrongSecretsPlain.class`.
- Відкрий цей клас у CFR, JADX, IntelliJ IDEA чи іншому декомпіляторі.

2. Перевірити, як зберігається секрет:
- Виконай `javap -c -p -classpath wrongsecrets-java.jar io.github.owasp.wrongsecrets.WrongSecretsPlain`.
- Знайди метод `getSecret()` і подивись на інструкцію `ldc`, яку він використовує.
- Зверни увагу, що секрет збережено як просту рядкову константу, а не обфусковано.

3. Відновити значення й надіслати його:
- Скопіюй рядок, який повертає `getSecret()`, із декомпілятора або виводу байткоду.
- Якщо хочеш ще одну швидку перевірку, інструменти на кшталт `strings wrongsecrets-java.jar` також допоможуть виявити читабельні константи.
- Надішли відновлений рядок як відповідь.
