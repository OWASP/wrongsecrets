Diese Aufgabe befasst sich speziell mit einem Geheimnis in einer .NET8-Binärdatei.

Diese Herausforderung lässt sich mit den folgenden alternativen Lösungsansätzen bewältigen:

1. Entdecke die Geheimnisse mit ILSpy.
- Beschaffen Sie sich die Binärdatei wrongsecrets-dotnet-<platform>. Dazu können Sie:
- aus dem Docker-Image abrufen
- Laden Sie es von https://github.com/OWASP/wrongsecrets-binaries/releases[Wrongsecrets Binaries] herunter.
- Installieren Sie .NET 8 und das .NET 8 SDK.
- Installieren Sie https://github.com/icsharpcode/ILSpy/tree/master/ICSharpCode.ILSpyCmd[ilspycmd]
- optional: Installieren Sie `sfextract`: `dotnet tool install -g sfextract`
- Entpacken Sie die eigenständige Binärdatei: `sfextract wrongsecrets-dotnet -o \./tmp`. Alternativ können Sie ilspy verwenden: `mkdir tmp && ilspycmd -d wrongsecrets-dotnet-linux -o ~/tmp`
- Wechseln Sie in den Ordner tmp und führen Sie den Befehl `ilspycmd dotnetproject.dll` aus, um die DLL zu dekompilieren und das Geheimnis zu finden.
Sie möchten die Tools nicht installieren? Dann schauen Sie sich den https://github.com/OWASP/wrongsecrets/tree/master?tab=readme-ov-file#want-to-play-but-are-not-allowed-to-install-the-tools[WrongSecrets Desktop container] an!
