=== Se cacher dans les binaires, partie 3 : le binaire Go

Notre troisième langage de prédilection pour une application compilée est Go. Avec sa popularité croissante, nous constatons une augmentation des secrets dissimulés dans les binaires. Saurez-vous trouver le secret dans notre binaire ?

Démystifions le mythe selon lequel « les secrets sont difficiles à trouver dans les applications compilées natives » pour Go : pouvez-vous trouver le secret dans https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-golang[wrongsecrets-golang] (ou https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-golang-arm[wrongsecrets-golang-arm], https://github.com/OWASP/wrongsecrets/tree/master/src/main/resources/executables/wrongsecrets-golang-linux[wrongsecrets-golang-linux]) ?

Essayez de télécharger le fichier binaire et de l'exécuter localement (par exemple `./wrongsecrets-golang<theversion you need> guess test`).
