Найпростіший спосіб зламати PIN-код у цьому сценарії – це виконати атаку методом перебору через обмежений діапазон можливих значень (від 0 до 99 999).

- Перебрати всі можливі PIN-коди (від 0 до 99 999).
- Для кожного PIN-коду обчисліть його хеш MD5, щоб отримати ключ розшифрування, та спробуйте розшифрувати наданий зашифрований текст.
- Якщо розшифрований текст дорівнює `the answer`, ви знайшли правильний PIN-код.
