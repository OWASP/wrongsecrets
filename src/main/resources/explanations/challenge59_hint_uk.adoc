=== Підказка до завдання 59

Шукаєте URL-адресу вебхука Slack? Ось кілька порад для початку:

==== Де шукати

1. **Змінні середовища**: URL-адреса вебхука зберігається у змінній середовища під назвою `CHALLENGE59_SLACK_WEBHOOK_URL`
2. **Перевірка програми**: Ви можете перевірити змінні середовища через програму або контейнер

==== Процес деобфускації

URL-адресу вебхука було обфусковано за допомогою поширеного методу:

1. **Подвійне кодування Base64**: оригінальна URL-адреса була закодована в Base64 двічі.
2. **Процес**: Оригінал → Base64 → знову Base64
3. **Для декодування**: Зворотний процес (декодуйте base64 двічі)

==== Що ви шукаєте

- URL-адреси вебхуків Slack відповідають шаблону: `https://hooks.slack.com/services/...`
- Вони містять три сегменти шляху після `/services/`
- Приклад формату: `https://hooks.slack.com/services/T123456789/B123456789/abcdefghijklmnopqrstuvwx`
- Сегменти URL-адреси представляють: ID команди / ID каналу / Секретний токен

==== Інструменти, які ви можете використовувати

- **Декодер Base64**: будь-який онлайн-декодер Base64 або інструмент командного рядка
- **Командний рядок**: `echo "encoded_string" | base64 -d`
- **Консоль браузера**: `atob("encoded_string")` у JavaScript

==== Навчання з безпеки

Цей челендж навчить вас про ризики, пов'язані з вебхуками:
- Як зловмисники можуть знаходити завуальовані URL-адреси вебхуків
- Чому URL-адреси вебхуків є конфіденційними обліковими даними, які потребують захисту
- Потенціал для несанкціонованої публікації повідомлень та соціальної інженерії
- Ризик жорстко закодованих URL-адрес вебхуків у змінних середовища
- Як відкриті вебхуки можуть призвести до пошкодження репутації та розкриття інформації
