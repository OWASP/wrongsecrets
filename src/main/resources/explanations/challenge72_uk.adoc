=== Завдання 72: Знайдіть секрет у стенограмі агента ШІ для кодування

ШІ-агенти для кодування, як-от Codex, Claude Code та Cursor, читають файли, виконують команди та створюють детальні стенограми сесій. Коли розробник просить агента налагодити проблему з розгортанням, агент може прочитати файли конфігурації, що містять секрети, і вивести ці значення у вивід своєї сесії.

Цей застосунок містить стенограму сесії Codex, у якій розробник попросив агента розібратися з невдалим розгортанням у staging. У стенограмі зафіксовано, як агент читає файл `.env.staging` і виводить його вміст — зокрема токен розгортання — як частину звичайного процесу налагодження.

Завантажте стенограму за посиланням link:/challenges/challenge-72/codex-session-transcript.md[`/challenges/challenge-72/codex-session-transcript.md`] і знайдіть токен розгортання staging, який був розкритий під час сесії.

Вихідний код також доступний за посиланням link:https://github.com/OWASP/wrongsecrets/blob/master/src/main/resources/challenges/challenge-72/codex-session-transcript.md[`src/main/resources/challenges/challenge-72/codex-session-transcript.md`].

[NOTE]
====
Токен природно з'являється у виводі стенограми — агент не мав наміру його розкрити, він просто прочитав файл у процесі налагодження.
====
