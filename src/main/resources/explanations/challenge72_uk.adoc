=== Завдання 72: Знайдіть секрет у стенограмі кодуючого агента штучного інтелекту

Агенти штучного інтелекту, такі як Codex, Claude Code та Cursor, читають файли, виконують команди та створюють детальні стенограми сеансів. Коли розробник просить агента налагодити проблему розгортання, агент може зчитувати файли конфігурації, що містять секрети, та відображати ці значення у виводі сеансу.

Ця програма надсилає стенограму сеансу Codex, де розробник попросив агента дослідити невдале проміжне розгортання. Стенограма фіксує, як агент зчитує файл `.env.staging` та виводить його вміст, включаючи токен розгортання, як частину звичайного робочого процесу налагодження.

Завантажте стенограму за посиланням:link:/challenges/challenge-72/codex-session-transcript.md[`/challenges/challenge-72/codex-session-transcript.md`] та знайдіть токен проміжного розгортання, який був оприлюднений під час сеансу.

Джерело також доступне за посиланням: link:https://github.com/OWASP/wrongsecrets/blob/master/src/main/resources/challenges/challenge-72/codex-session-transcript.md[`src/main/resources/challenges/challenge-72/codex-session-transcript.md`].

[NOTE]
====
Токен природним чином відображається у виведеному транскрипті — агент не мав наміру його витікати, він просто зчитав файл у рамках процесу налагодження.
====
