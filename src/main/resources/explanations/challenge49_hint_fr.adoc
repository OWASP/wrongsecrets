La manière la plus simple de déchiffrer le code PIN dans ce scénario est d'effectuer une attaque par force brute en raison de la plage limitée de valeurs possibles (de 0 à 99 999).

- Parcourir tous les codes PIN possibles (de 0 à 99 999).
- Pour chaque code PIN, calculez son hachage MD5 pour obtenir la clé de déchiffrement et essayez de déchiffrer le texte chiffré fourni.
- Si le texte déchiffré est égal à `the answer`, vous avez trouvé le bon code PIN.
