Die Agenten-Anweisungsdateien werden zusammen mit dem Entwicklungscontainer ausgeliefert.
Ordner `.devcontainer`:

- `.devcontainer/AGENTS.md`
- `.devcontainer/CLAUDE.md`
- `.devcontainer/.cursor/rules/project.mdc`
- `.devcontainer/.windsurfrules`

Drei davon verweisen lediglich auf den Speicherort der gemeinsamen Anmeldeinformationen. Einer davon
Der Wert von `STAGING_DEPLOY_TOKEN` wird in einem Shell-Snippet inline eingefügt. Dieser Wert ist
die Antwort.

Wenn Sie den Entwicklungscontainer nicht verwenden, können Sie dieselben Dateien auch so lesen.
