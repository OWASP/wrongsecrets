Diese Herausforderung lässt sich mit folgenden Schritten lösen:

1. Öffnen Sie https://console.cloud.google.com/logs/query[*Cloud Logging*] (ehemals Stackdriver) für das Projekt, das Ihren GKE-Cluster hostet.
2. Abfrage des vom Programm ausgegebenen Audit-Ereignisses:
+
[source,shell]
----
gcloud logging read \
  'resource.type="k8s_container" AND textPayload:"encoded credential"' \
  --limit=5 --format='value(textPayload)'
----
3. In der Konsole können Sie denselben Filter im Abfragefeld des Log Explorers verwenden: `resource.type="k8s_container"` kombiniert mit `textPayload:"encoded credential"`.
4. Extrahieren Sie den Base64-Blob aus der Nachricht und dekodieren Sie ihn: `echo '<blob>' | base64 -d`. Dieser dekodierte Wert ist die Antwort.

Sie sehen noch nichts? Das Ereignis wird beim ersten Öffnen der Herausforderung ausgelöst. Rufen Sie die Seite also einmal auf und versuchen Sie es erneut.
