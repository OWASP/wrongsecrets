=== Завдання 73: Знайдіть секрет у файлах інструкцій агента

ШІ-агенти для кодування завантажують на кожній
сесії файли інструкцій і контексту з репозиторію: `AGENTS.md`, `CLAUDE.md`, `.cursor/rules/*.mdc`, `.windsurfrules` та
подібні. Оскільки ці файли — „просто документація“, їх рідко перевіряють так само ретельно,
як вихідний код, хоча їх читає модель, копіює на кожен комп'ютер розробника
і додає до керування версіями.

Цей репозиторій містить такі файли інструкцій у своєму Dev Container. Вони лежать
у теці link:https://github.com/OWASP/wrongsecrets/tree/master/.devcontainer[`.devcontainer`]:

- `.devcontainer/AGENTS.md`
- `.devcontainer/CLAUDE.md`
- `.devcontainer/.cursor/rules/project.mdc`
- `.devcontainer/.windsurfrules`

Один із них вставляє спільні облікові дані так, щоб кожен агент повторно використовував
те саме значення „для зручності“. Прочитайте файли та надішліть розкритий токен staging.

[NOTE]
====
Тут нічого не кодовано і не зашифровано: саме так виглядає витеклий файл
контексту агента в реальному світі.
====
