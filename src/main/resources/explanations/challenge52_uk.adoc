=== Виклик «Викриті секрети Buildx»

Acme Inc., SaaS-компанія, що швидко розвивається, розширює свої контейнерні розгортання за допомогою Docker Buildx для оптимізації багатоплатформних збірок. Однак під час процесу збірки сталася серйозна помилка в конфігурації безпеки.

Під час [процесу Docker Buildx](https://github.com/OWASP/wrongsecrets/blob/master/.github/scripts/docker-create.sh#L365) конфіденційний секретний ключ, який мав залишатися тимчасовим та захищеним під час фази збірки контейнера, був випадково вбудований у файлову систему контейнера через неправильну конфігурацію. Цей секретний ключ, тепер доступний у запущеному контейнері та видимий у його скриптах збірки, становить значну загрозу безпеці у разі його використання.

Як нещодавно прийнятий консультант з безпеки Acme Inc., ваше завдання чітке: дослідити контейнер, виявити розкритий секретний код та повідомити про нього команді. Виявивши цю вразливість, ви допоможете Acme Inc. зрозуміти ризики та впровадити кращі практики для захисту свого конвеєра розгортання.
