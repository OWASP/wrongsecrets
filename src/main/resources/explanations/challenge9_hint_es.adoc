Puedes resolver este desafío mediante las siguientes soluciones alternativas:

1. Analice el archivo terraform.tfstate con Trufflehog:
- Después de haber construido la infraestructura siguiendo las instrucciones del archivo README de la carpeta `aws`, permanezca en esa carpeta y ejecute `trufflehog3 --output=terraform-infra.json --format=json .`
- Ahora, abre el archivo terraform-infra.json y empieza a buscar la contraseña.

2. Encuentra el secreto en AWS Secrets Manager (esta es la forma más sencilla, prueba las otras :) )
- Inicie sesión en AWS https://console.aws.com/[Console] con la cuenta con la que creó la configuración de WrongSecrets.
- Ve al administrador de secretos de AWS
- obtener los datos de wrongsecrets1

3. Encuentra el secreto accediendo al POD mediante exec-in.
- Asegúrese de tener Kubectl instalado como se define en el archivo README.MD y asegúrese de que kubectl esté configurado para enviar comandos al clúster correcto.
- Ahora ejecuta `kubectl get pods`. Aquí verás todos los Pods activos en el espacio de nombres en el que te encuentras, que para esta aplicación normalmente es `default` (a menos que tu administrador/tutor especifique lo contrario).
- ahora, para tu instancia del pod WrongSecrets, haz `kubectl exec -it secret-challenge-<rest of the name of the pod from the prev.step> -- sh`.
- Ahora examina los datos que puedes encontrar en `/mnt/secrets-store`.
