*Por qué copiar las especificaciones es una mala idea*

Cuando intentas implementar controles criptográficos, puede resultar muy desalentador: hay muchos detalles a los que debes prestar atención.
A estas alturas ya sabrás que no se recomienda copiar cada primitivo de un ejemplo para tu propia implementación. En este ejemplo, copiamos la clave HMAC de una especificación NIST, que cualquiera podría haber intentado usar para descifrarla mediante fuerza bruta.

Tenga en cuenta que copiar claves de especificaciones/ejemplos no solo es válido para HMAC, sino para cualquier operación criptográfica (firma, cifrado, descifrado, etc.).

¿Aún necesitas generar una clave? Asegúrate de usar un generador de claves aleatorias seguro y la biblioteca adecuada para tu entorno de ejecución para generar la clave.

Para mayor seguridad, utilice un sistema de generación y/o derivación de claves en el que cada mensaje nuevo tenga una clave diferente. De esta forma, se logra la confidencialidad absoluta hacia adelante. Esto garantiza que los mensajes antiguos no puedan descifrarse si una clave se ve comprometida.
