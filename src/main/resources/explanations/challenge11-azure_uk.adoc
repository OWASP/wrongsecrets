=== Сховище ключів Azure, частина 3

У нашому кластері AKS є два зв'язки Azure Identity. Вони використовуються Azure для введення метаданих. У нашому випадку ми використовуємо їх для доступу до Azure Key Vault.

Цікаво, що сховище ключів встановлює дозволи для кожного сховища, а не для кожного секретного коду. На жаль, розробники мають лише одне сховище ключів для двох ідентифікаційних даних...

Підказка: Існує прив’язка до `separate-workload-pod-id`. Спробуйте створити под із правильними мітками, щоб викрасти wrongsecret-3 (див. також https://docs.microsoft.com/en-us/azure/aks/use-azure-ad-pod-identity#run-a-sample-application [документація aks]).
