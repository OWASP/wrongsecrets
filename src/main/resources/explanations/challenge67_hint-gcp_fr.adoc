Vous pouvez relever ce défi en suivant les étapes suivantes :

1. Ouvrez https://console.cloud.google.com/logs/query[*Cloud Logging*] (anciennement Stackdriver) pour le projet qui héberge votre cluster GKE.
2. Rechercher l'événement d'audit émis par l'application :
+
[source,shell]
----
gcloud logging read \
  'resource.type="k8s_container" AND textPayload:"encoded credential"' \
  --limit=5 --format='value(textPayload)'
----
3. Dans la console, vous pouvez utiliser le même filtre dans la zone de requête de l'explorateur de journaux : `resource.type="k8s_container"` combiné avec `textPayload:"encoded credential"`.
4. Extrayez le blob Base64 du message et décodez-le : `echo '<blob>' | base64 -d`. La valeur décodée est la réponse.

Vous ne voyez toujours rien ? L’événement est déclenché lors de la première ouverture du défi. Veuillez donc consulter la page une première fois, puis relancer la requête.
