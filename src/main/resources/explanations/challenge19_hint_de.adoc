Diese Aufgabe befasst sich speziell mit einem Geheimnis in einer C-Binärdatei.

Diese Herausforderung lässt sich mit den folgenden alternativen Lösungsansätzen bewältigen:

1. Entdecken Sie die Geheimnisse mit https://ghidra-sre.org/[Ghidra].
- Installieren Sie https://ghidra-sre.org/[Ghidra].
- Starten Sie es mit `ghidraRun`.
- Laden Sie die Anwendung `wrongsecrets-c` in Ghidra, indem Sie ein neues Projekt auswählen, dann die Datei importieren und anschließend darauf doppelklicken.
- Erlauben Sie Ghidra, die Anwendung zu analysieren.
- Suche nach dem Geheimnis: Gehe links auf `Functions` und wähle `_secret` aus. Das Geheimnis wird nun rechts angezeigt. Es handelt sich um eine Zeichenkette in C.
- Suchen Sie nach demselben Geheimnis, das als Zeichenarray „versteckt“ ist: Gehen Sie links auf `Functions` und wählen Sie `_secret2` aus. Rechts wird Ihnen eine Bezeichnung angezeigt. Öffnen Sie nun links `Labels`, wählen Sie die von `_secret2` zurückgegebene Bezeichnung (`_secret2.label`) aus und finden Sie die Antwort in der Mitte. Es handelt sich um ein Zeichenarray in C.

2. Entdecken Sie die Geheimnisse mit https://www.radare.org[radare2].
- Installieren Sie https://www.radare.org[radare2] entweder mit `brew install radare2` auf einem Mac oder folgen Sie diesen Schritten: `git clone https://github.com/radareorg/radare2; cd radare2 ; sys/install.sh`
- Starten Sie die r2-Analyse mit `$ r2 -A wrongsecrets-c`
- Filtern Sie Funktionen nach dem Begriff `secret` mithilfe von afl: `afl~secret`, um die Liste der Funktionen zu erhalten
- Verwenden Sie den Befehl `pdf @ sym._secret`, um die disassemblierte Ausgabe der Funktion anzuzeigen, die das Geheimnis zurückgibt.
- Verwenden Sie den Befehl `pdf @ sym._secret2`, um die disassemblierte Ausgabe der Funktion anzuzeigen, die secret2 zurückgibt.


Sie möchten die Tools nicht installieren? Dann schauen Sie sich den https://github.com/OWASP/wrongsecrets/tree/master?tab=readme-ov-file#want-to-play-but-are-not-allowed-to-install-the-tools[WrongSecrets Desktop container] an!
