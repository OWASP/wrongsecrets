*Чому публікувати скріншоти журналів у задачі GitHub — погана ідея*

Не слід публікувати скріншоти журналів у задачі GitHub, тому що:
1. Дані є публічними (навіть у приватному сховищі, часто більш публічними, ніж можна було б сподіватися)
2. Знімки екрана не можна редагувати, як текст. Навіть якщо секрет розмитий, це можна виправити.

Перевірте наявність будь-яких секретних витоків у виводі та використовуйте розмітку блоків коду для публікації логів у проблемі GitHub. Це також набагато зручніше для розробників, які намагаються допомогти вам з налагодженням :).
Якщо облікові дані викрито, негайно скасуйте або поверніть їх та видаліть публікацію чи вкладення, де це можливо; враховуйте, що їх уже скопійовано.
