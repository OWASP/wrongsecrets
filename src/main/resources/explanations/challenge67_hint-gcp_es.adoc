Puedes resolver este desafío siguiendo estos pasos:

1. Abra https://console.cloud.google.com/logs/query[*Cloud Logging*] (anteriormente Stackdriver) para el proyecto que aloja su clúster GKE.
2. Consultar el evento de auditoría que emite la aplicación:
+
[source,shell]
----
gcloud logging read \
  'resource.type="k8s_container" AND textPayload:"encoded credential"' \
  --limit=5 --format='value(textPayload)'
----
3. En la consola puede usar el mismo filtro en el cuadro de consulta del Explorador de registros: `resource.type="k8s_container"` combinado con `textPayload:"encoded credential"`.
4. Toma el blob Base64 del mensaje y decodifícalo: `echo '<blob>' | base64 -d`. Ese valor decodificado es la respuesta.

¿Aún no ves nada? El evento se emite la primera vez que se abre el desafío, así que accede a la página una vez y vuelve a intentarlo.
