=== .ssh Бастіон?

Ми бачили багато так званих "бастіонних контейнерів". Тут люди створюють Docker-контейнер і вбудовують "секрет" для автентифікації на хості всередину контейнера. Цей секрет часто є парою ключів SSH, яка використовується для автентифікації на хості. У деяких випадках пара ключів передається git, а в деяких випадках вона вводиться в контейнер перед тим, як контейнер буде завантажено до реєстру.

Щоб контейнер бастіону працював, нам потрібно вбудувати файл конфігурації SSH (`.ssh/config`), щоб спростити налаштування SSH-з'єднання, зберігаючи конфігурації, специфічні для хоста.

Чи можете ви знайти закритий ключ? Вставте його вміст у поле для відповіді нижче.
