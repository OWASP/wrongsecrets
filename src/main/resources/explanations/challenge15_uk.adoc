=== Історія Git

Одна з помилок, яку ми часто робимо, коли передаємо секрети до Git, — це спроба позбутися їх, не обертаючи секрет.
Що ще гірше, так це те, що без належного перевизначення коміту секретом та/або видалення коміту, він залишиться в історії назавжди.

Отже, ми зберегли деякі ключі доступу AWS у git як "помилку", чи можете ви їх знайти?

Примітка: відповідь містить один із 3 профілів облікових даних AWS, які ви знайдете в коміті, його коментарі Java, але без розмітки коментарів Java як один рядок.
Або ж ви можете просто надати секретний ключ доступу, який нам потрібен.

Примітка 2: Чи знаєте ви, що це робочі ключі доступу, примітка: відмова від відповідальності [Це не «звичайні» ключі доступу AWS: це токени Canary! Хоча ви можете виконати з ними команду `aws sts get-caller-identity`. Коли ви їх використовуєте, деякі ваші дані (IP/агент) записуються.]?!
Щоб дізнатися більше, перейдіть за посиланням https://wrongsecrets.herokuapp.com/stats[stats], коли ви їх спробували!
