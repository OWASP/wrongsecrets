Ви можете вирішити цю проблему за допомогою таких альтернативних рішень:

1. Знайдіть секрет у Azure Key Vault (це найпростіший спосіб, спробуйте інший :) ):
- Увійдіть до Azure https://portal.azure.com[хмара], використовуючи обліковий запис, за допомогою якого ви створили налаштування WrongSecrets.
- Перейдіть до сховища ключів
- Отримати дані з wrongsecret2

2. Знайдіть секрет, виконавши команду в POD
- Переконайтеся, що у вас встановлено Kubectl, як визначено у файлі README.MD, і що kubectl налаштовано на надсилання команд до правильного кластера.
- тепер виконайте команду `kubectl get pods`. Тут ви побачите всі поди, активні в просторі імен, у якому ви знаходитесь, який для цієї програми зазвичай є `default` (якщо інше не вказано вашим адміністратором/тренером).
- для вашого екземпляра пода WrongSecrets виконайте команду `kubectl exec -it secret-challenge-<rest of the name of the pod from the prev.step> -- sh`.
- перегляньте дані, які ви можете знайти в `/mnt/secrets-store`
