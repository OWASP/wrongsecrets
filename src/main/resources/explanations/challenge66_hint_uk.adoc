У цьому завданні використовується обфускований JAR-файл Java CLI.

Ви можете вирішити це таким чином:

1. Знайдіть, де знаходяться обфусковані дані:
- Завантажити `wrongsecrets-java-obfuscated.jar`.
- Запустіть `jar tf wrongsecrets-java-obfuscated.jar` та знайдіть `io/github/owasp/wrongsecrets/WrongSecretsObfuscated.class`.
- Відкрийте цей клас у CFR, JADX, IntelliJ IDEA або іншому декомпіляторі.
- Шукайте статичні поля, які містять ключ XOR та закодовані секретні байти.

2. Перевірте точну логіку декодування:
- Виконайте команду `javap -c -p -classpath wrongsecrets-java-obfuscated.jar io.github.owasp.wrongsecrets.WrongSecretsObfuscated`.
- У виводі знайдіть блок `static { ... }`, який заповнює `XOR_KEY_CHARS` та `ENCODED_SECRET`.
- Потім знайдіть `decodeSecret()` та зверніть увагу, що кожен закодований байт обробляється за допомогою операції XOR з одним байтом з ключа, повторюючи ключ за модулем арифметики.

3. Відтворіть секрет самостійно:
- Перетворити значення `XOR_KEY_CHARS` на байти.
- Скопіюйте значення байтів `ENCODED_SECRET` з байт-коду або декомпільованого вихідного коду.
- Виключає АБО кожного закодованого байта з відповідним байтом ключа, переходячи до кінця ключа.
- Розшифруйте отриманий байтовий масив як UTF-8, щоб відновити секрет, а потім надішліть це значення як відповідь.
