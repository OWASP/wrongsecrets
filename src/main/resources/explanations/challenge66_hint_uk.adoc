Це завдання використовує обфускований JAR-файл Java CLI.

Ти можеш розв'язати його так:

1. Знайти, де зберігаються обфусковані дані:
- Завантаж `wrongsecrets-java-obfuscated.jar`.
- Виконай `jar tf wrongsecrets-java-obfuscated.jar` і знайди `io/github/owasp/wrongsecrets/WrongSecretsObfuscated.class`.
- Відкрий цей клас у CFR, JADX, IntelliJ IDEA чи іншому декомпіляторі.
- Пошукай статичні поля, які містять ключ XOR і закодовані байти секрету.

2. Перевірити точну логіку декодування:
- Виконай `javap -c -p -classpath wrongsecrets-java-obfuscated.jar io.github.owasp.wrongsecrets.WrongSecretsObfuscated`.
- У виводі знайди блок `static { ... }`, який заповнює `XOR_KEY_CHARS` і `ENCODED_SECRET`.
- Потім знайди `decodeSecret()` і зверни увагу, що кожен закодований байт XOR-ться з одним байтом ключа, а ключ повторюється за допомогою арифметики по модулю.

3. Самостійно відновити секрет:
- Перетвори значення `XOR_KEY_CHARS` на байти.
- Скопіюй значення байтів `ENCODED_SECRET` із байткоду або декомпільованого вихідного коду.
- XOR- кожен закодований байт із відповідним байтом ключа, повертаючись на початок, коли доходиш до кінця ключа.
- Розкодуй отриманий масив байтів як UTF-8, щоб відновити секрет, і надішли це значення як відповідь.
